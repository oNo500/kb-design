# Obsidian 工具归属

状态：已采纳，2026-09-05。用户确认将 `kb-obsidian` 作为设计的配套工具迁入本仓库，保留原提交历史和独立 vault。

## 工具归属

工具位于 `tools/obsidian/`，保留 Python 包名与 `kb-obsidian` 命令。概念、词表、应用表示与文件生成继续分层，但不再用两个 Git 仓库维持这种分层。原应用目录保留作迁移备份；实际笔记和生成实例不迁入设计仓库。

## 版本依据

工具默认定位所在设计仓库，保留显式 `--design-root`。取消设计提交白名单，仍要求干净的 Git checkout，并读取和校验正式输入；清单继续记录实际提交与输入哈希。未提交工作目录不冒充已提交版本。

旧 vault 清单保持可读。刷新时验证清单版本、旧提交属于当前历史、旧输入与 Git 中的字节一致，再检查写集与引用；不因取消白名单放宽旧来源真实性或用户内容保护。应用版本和清单格式不在本次改变。

## 刷新兼容

刷新继续只更新 `kb/` 和 `app/manifest.json`。Base 的排版差异仅在原清单哈希能由生成模板证明、且 YAML 内容相同时接受；参考区的等价 Base 排版也予以保留。实质变化仍拒绝覆盖。本次只在临时副本验证，不刷新实际 vault。

## 决定关系

本决定替代现行说明中的独立应用仓库和设计提交白名单安排；[词表参考刷新](obsidian-reference-refresh.md)的其他边界继续有效。[设计与应用分离](form-independence.md)及[应用约束与表示分层](application-profile-boundary.md)的语义分层不变，历史记录不重写。本次不批准正式消费者、来源或术语激活，也不构成发版。

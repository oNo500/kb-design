# 文档文件命名

状态：已采纳，2026-09-12。级别：L2。用户要求概念和设计正文增加固定前缀并使用中文文件名，确认具体命名示例和执行范围后批准实施。

## 命名规则

概念文使用“概念-名称.md”，设计正文使用“设计-名称.md”。名称取现有文章标题中的中文部分，去掉括号内英文；已由前缀表达的设计字样不重复。Application Profile、Reproducible Builds 等已有明确保留英文决定的名称继续沿用，不引入新译名。

主题目录保持不变。首页、阅读笔记、决定、提案、操作指南和生成术语表沿用原文件名。文档分类与准入效力不因名称改变；正式术语、概念身份、生成输入和授权内容不变。

## 迁移边界

[命名迁移清单](../../../work/plans/2026-09-12-docs-chinese-files.json)保存旧路径、新路径、文档职责和原哈希。现行导航与链接指向新路径，历史记录按原基线及连续迁移关系解释。既有决定、数据和历史记录不因重命名改写。

当前[文件命名规则](../writing/设计-写作规则.md#文件命名)作为日常编辑入口。

# 证据阶段

状态：已采纳，2026-08-31。决定记录只追加不修改；推翻时新建一条并把本条标为“被替代”。

## 背景

首轮来源迁移账本已覆盖 3,187 个身份，其中 700 行安全关闭，2,487 行仍缺真实外部状态、定位、角色资格或关系依据。逐条补齐全部旧断言耗时很高，其中一部分没有正式消费者，也不会进入新的正式结构。

## 决定

剩余工作按价值和必要性分三类。

1. 当前阶段继续完成模式、校验器、反向索引、只读探测、迁移账本、复核义务、候选生成、交付绑定、回滚能力，以及术语模式和生成工具。当前阶段可以形成完整可运行候选，但不宣称严格来源切换、草案生效或发版。
2. 必要但取证昂贵的工作记入下一阶段：31 个现行来源的发布方状态和替代关系；进入正式活动数据所必需的逐值 `basis`；仍有正式消费者的关键 `source` 与 `match`；13 个受正式文档重写影响的旧字段身份；来源和术语的严格切换。
3. 无正式消费者、不会进入新正式结构、仅为补全旧断言而进行的来源或关系研究不做。旧值和处置保留在迁移审计中，标为低价值审计关闭，不取得新效力，也不进入下一阶段待办。

每个延期项须记录稳定身份、必要性、消费者、缺失证据、重新启动条件和目标阶段。没有消费者或重新启动条件的项不得伪装成延期，直接审计关闭。

## 后果

- 当前阶段完成标准从“全部 3,187 行零阻断并严格切换”改为“基础设施、账本和候选能力完成，当前阶段项闭合，下一阶段项和低价值关闭项均可审计”。
- 严格来源 handoff、正式数据应用、草案生效和术语正式激活仍在下一阶段，不能由基础设施完成状态替代。
- 下一阶段只研究能改变正式结果的高价值子集，不恢复全量逐行研究、低价值测试或重复复审。

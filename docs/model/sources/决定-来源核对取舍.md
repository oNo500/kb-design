# 来源核对取舍

状态：已采纳，2026-09-05。用户确认按价值决定是否核对：有价值或重要的事实，即使处理成本较高，也应核对。

## 核对顺序

先处理影响稳定身份、字段语义、实际引用及正式切换的事实。已有证据足够时直接复用；需要补核时只处理真实缺口，不重复已完成的取证。

离线且可直接阅读的材料仍优先使用，但材料复杂或耗时不再是自动“不核对”的理由。本决定替代[来源执行](source-execution-boundary.md)中按复杂程度一律跳过的取舍。低价值、无实际使用且不影响迁移的内容可以标记“不核对”；跳过必需事实仍阻断对应记录，不能被算作迁移完成。

## 权限范围

新的外部材料应说明对象、用途及预计成本，再按具体授权执行。本次没有自动开放批量下载、扫描件处理或来源事实采纳。已采纳的 P1–P4 不重复研究，来源角色、字段语义与正式切换仍分别满足各自决定条件。

恢复使用 Git，不新增补偿回滚或长期旧格式兼容层；不以增加工具代替证据和字段方案。

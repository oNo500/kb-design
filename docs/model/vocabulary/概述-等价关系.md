# 等价关系

三类关系的总体区别见[词表关系](概述-词表关系.md)。本篇进一步说明等价关系怎样建立和使用。

## 首选词控制

> **【类型规则｜以叙词表的首选词控制为例】** 以下说明采用首选词和非首选词入口的情形，不能直接套给同义词环。

当一个概念有不同表达时，可以选择一个首选词，让其他入口指向它。Z39.19 §8.2 使用一对标示。

| 标示 | 方向 | 作用 |
|---|---|---|
| USE | 非首选词 → 首选词 | 告诉使用者应采用哪个词 |
| UF（USED FOR） | 首选词 → 非首选词 | 列出这个首选词所对应的其他入口 |

两者必须相互对应。[标准 §8.1.1、§8.2](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

## 教学例子

> **【教学例子｜假设选择“自行车”为首选词】** 本例用于解释标示方向，并非标准原例。

```text
脚踏车  USE  自行车
自行车  UF   脚踏车
```

第一行引导使用“自行车”；第二行说明“脚踏车”是它的入口。UF 并不是建议反过来改用非首选词。

## 等价的范围

> **【规则范围｜Z39.19 §8.2】** 本节的等价不只包含严格同义，也涉及特定用途下的替代约定。

§8.2 讨论五种情况。下面保留原文类别，中文用于解释。

| 原文类别 | 含义 |
|---|---|
| Synonyms | 不同的词，在广泛语境中意义相同或非常接近 |
| Lexical variants | 同一表达的拼写、词序、语法或缩写形式不同 |
| Near-synonyms | 含义有区别，但在特定词表用途下作为等价表达处理 |
| Generic posting | 用较宽的类别名统一承接较细的成员名称 |
| Cross-references to elements of compound terms | 将复合词引向需要组合使用的组成词 |

词表中的等价关系，有时表达的是特定用途下的替代约定，不能直接解释为这些词在所有语境中意义完全相同。

标准对后几种处理有条件限制。例如，将较细名称统一归入较宽名称，会降低表达的具体程度；§8.2.4 将其限制在主题外围领域，或有关资料数量尚不足以支持进一步细分的情形。能稳定区分且值得分别表示的概念，应保留区别。[标准 §8.2.3–§8.2.5](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

## 同义词环

> **【类型区别｜同义词环】** 此处回到不同结构之间的区别。

同义词环只需把检索时等价的表达组织成组，不要求建立上面的“首选词—非首选词”方向。因此，不能把 USE／UF 的表示要求直接套给同义词环。[标准 §5.4.2](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

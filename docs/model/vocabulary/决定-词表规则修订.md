# 词表规则修订

状态：已采纳，2026-09-19。用户审阅[规则依据审查](../../../work/reviews/2026-09-19-vocabulary-rule-audit.md)后要求“按照审查结果执行吧”。本决定采纳其中明确的修订与限制移除，保留有依据的选择；四项待核不因本次执行变成已解决。

## 采用内容

| 审查项 | 采用结果 | 规则位置 |
|---|---|---|
| F01 分组关系 | 采用 SKOS-Thes 时检查 ConceptGroup 两端、与数组互斥、传递、逆向及成员包含；不当作通用集合属性 | [分组扩展](设计-词表数据规范.md#分组扩展) |
| F02 元数据类型 | 标准允许值、自有表示和来源原值分开；语言允许资源或 BCP 47 文字，其他元数据按属性含义保留合法表示 | [来源兼容字段](设计-词表数据规范.md#来源兼容字段) |
| F03 同步方法 | 保存修改依据、来源变化、本地意图及冲突；取消通用层对三方算法的唯一指定，自动协调仍须完整语义检查 | [再同步规则](设计-词表维护.md#再同步规则) |
| F04 重建要求 | 移除每次必须重建的通用要求；保留结果与所选版本一致、清理失效内容及可核对恢复 | [增量同步](设计-多语言词表.md#增量同步) |
| F05 标题派生 | 移除 title 必须由 prefLabel 同值派生的通用限制；具体兼容输出可继续采用 | [词表字段](设计-词表数据规范.md#词表字段) |
| F06 默认语言 | 通用设计要求声明默认行为；原英文回退限定为现行中英文消费配置，不作为所有语言的固定默认 | [匹配与显示](设计-多语言词表.md#匹配与显示) |
| F07 字段基数 | 本地概念与概念组有名；一般集合和数组不一律必名。本地日期可选单值，来源日期不统一截断 | [集合名称](设计-词表数据规范.md#集合名称)、[来源与依据](设计-词表数据规范.md#来源与依据) |
| F08 标识策略 | 保留已分配身份及 UUIDv4 本地分配方案，补 RFC 依据、方案理由和 Web 发布边界 | [标识策略](设计-词表维护.md#标识策略) |
| F09 名称约束 | 词表、集合的普通标签为默认方式，来源已有或具体采用的 XL 名称完整保留；首选 Label 资源唯一性另列待核 | [语言与名称](设计-词表数据规范.md#语言与名称) |
| F10 交付记录 | 通用模型规定身份、版本、内容与证据可追溯；文件位置、字节摘要及文件集由适用交付合同落实 | [维护记录](设计-词表数据规范.md#维护记录)、[文件交付](../../practices/vocabulary/设计-词表工程能力.md#文件交付) |
| F11 发布门槛 | 有效发布图的标准矛盾无论新旧均须解决；原件异常、项目例外和受限材料分别说明，不混作已通过 | [校验范围](设计-词表数据规范.md#校验范围) |
| F12 名称联系 | 明确 labelRelation 的对称性及扩展用途，具体子属性不自动继承对称性 | [名称字段](设计-词表数据规范.md#名称字段) |

三方比较、文件交付、同值标题和英文默认仍可用于适合的具体方案，本决定取消的是未经充分理由施加给所有实现的限制，不删除现有能力或历史记录。

## 待核事项

| 审查项 | 保留的问题 | 本次处理边界 |
|---|---|---|
| R12 首选资源唯一 | 两个来源的不同 Label 具有相同文字和完整语言标签，且各有独立依据时，如何选择或保留首选引用 | 标准允许同文 Label 保持不同身份；既有自有主图的额外资源唯一规则暂保留原适用范围，不扩到来源图，不自动合并或裁剪来源身份。仍需具体编辑与消费需求决定是否调整 |
| R30 层级细分 | 整体部分等关系的完整业务成立条件 | 保留来源已声明的类型，不把一般 isPartOf、目录位置或未核条件自动采纳为新的层级关系 |
| R35 组合映射 | 成熟交换表示及具体消费语义 | 保留组合与依据，不拆成错误的简单映射；未选定表示不作为已完成的交换接口 |
| R70 ISO 正文 | 未取得的权威条款及缺页 | 继续标为未核，不用本地笔记、schema 或实现结果补写条款 |

R12 的待核场景应同时保留两个名称身份、同文事实、来源版本及各自依据，比较“仅限制文字值”和“额外选择唯一首选资源”对编辑、显示和追溯的影响。在形成具体决定前，不能把其中一种方案自动变成新规则。

## 决定关系

[整体设计](决定-词表整体设计.md)中采用三方比较的条款，按本决定保留其冲突保护目标，并将具体算法归入实践；稳定身份、按需整合及映射用途继续有效。

[多语言采纳](决定-多语言词表.md)中的“保留英文回退”按现行消费范围解释，不再规定通用默认语言。原有中文批译、语种启用和名称依据授权不扩展。

[维护约束](决定-词表维护约束.md)的统一校验目标，按本决定明确原件诊断、有效图一致性及项目例外的界限；不能以只检查新增错误替代有效图检查。其他已采纳的退出、引用和名称登记职责继续有效。

实际实现仍须按新目标单独核对和验收，不能由文档采纳推定已经满足。旧审查保留为采纳前证据，逐项执行及保留项见[修订记录](../../../work/reviews/2026-09-19-vocabulary-rule-fixes.json)。

## 标准边界

2026-09-19，用户在确认极力避免自定、审阅三项修复建议后回复“执行吧”。本节调整上文对应约束和待核状态，原记录作为形成过程保留。

| 事项 | 本次采用 | 对旧规则的影响 |
|---|---|---|
| 首选名称 | 按 SKOS 普通标签与 XL 投影检查同语言首选文字唯一；同文不同 Label 分别保留身份和依据 | 撤销自有主图“同语言至多一个首选 Label 资源”的额外限制；R12 在本决定范围内解决，不再用显示去重合并身份 |
| 层级判据 | 采用 ANSI/NISO Z39.19-2005 (R2010) §8.3–§8.3.4，按原文条件、例证和反例判断 | R30 的项目业务判据据此明确；不宣称已核全部 ISO 条款，不自动增加关系属性或改写已收录关系 |
| 组合接口 | 自有简单映射合同以单个概念为两端；来源组合原表示及依据继续保存 | 撤销将自定 AND／OR 嵌套结构作为正式合同的部分；R35 的成熟交换方案继续研究 |
| 材料范围 | 标准全文的取得、实际核读和采用范围分别记录 | R70 的 ISO 权威正文缺口继续保留，不因取得另一部标准而视为补齐 |

取消额外资源唯一限制是标准允许范围内、为保留来源身份作出的项目选择，并非 SKOS 强制所有系统采用相同编辑流程。文字相同也不自动证明概念对应；名称使用关系和具体采用依据仍须成立。

NISO §8.3 的单语分类法与叙词表业务条件被明确用于本项目概念层级；跨语言对应仍按多语言设计处理。整体部分限制和多上位条款连读，具体关系无法与定义及原文条件对应时保留待判断，不用父节点数量或自定阈值替代论证。

词表内复合等价的 CompoundEquivalence 与跨词表组合映射分别研究。本次不自动采纳该扩展、不自造交换本体，也不以“候选格式”取得试用效力；来源已有结构仍保留。当前研究边界为 R35 的组合方案和 R70 的未核 ISO 材料。

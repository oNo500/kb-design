# 首选词与名称形式

一个概念有多个叫法时，需要选择用于一致表达的名称，并保留其他叫法的查找作用。[词的范围](概述-词的范围.md)说明含义边界，本篇讨论首选形式及其选择依据。

## 适用范围

> **【适用范围｜采用首选词的受控词表】** 本篇主要依据 NISO Z39.19 §6.6，适用于需要选择首选形式的词表。同义词环不要求指定首选词，不能把这里的规则推广到所有结构。

## 首选词的意义

首选词是在特定词表中选定的规范表达。选择应当依据领域文献、组织用法和用户用法，并记录依据；其他等价形式可以作为入口，引导到首选形式。[标准 §6.6–§6.6.1](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

> **【教学例子｜自拟】** 假设某份词表依据使用情况选择“自行车”作为首选词，并把“脚踏车”作为同一概念的非首选词。

```text
脚踏车  USE  自行车
自行车  UF   脚踏车
```

这里的意思是：在该词表中统一使用“自行车”，同时保留“脚踏车”的查找入口。它没有断言“脚踏车”在日常语言中是错误表达。

> **【类型用法｜叙词表】** 上面的 USE／UF 是[等价关系](概述-等价关系.md)中的标示；具体软件也可以用其他显示方式呈现这种引导。

## 名称选择

> **【标准规则归纳｜§6.6】** 这些判断有各自条件，不能统一简化成“总选全称”或“总选专业名称”。

| 情况 | 选择依据 |
|---|---|
| 多个常用叫法 | 结合文献、组织及用户用法，选择适合该词表的形式 |
| 拼写变体 | 采用有依据的通行拼写，保持一致，并保留常见变体入口 |
| 缩写与全称 | 缩写已充分通行、全称很少使用时，可选缩写；缩写不熟悉或有歧义时，选全称 |
| 通俗名与科学名 | 在表示同一概念的前提下，选择用户更可能查找的形式 |
| 新词、行话与俚语 | 没有广泛接受的替代表达时，可以采用；有既有规范表达时，可作为入口 |
| 外来词与译名 | 依据在该领域中的接受程度选择，并连接等价形式 |
| 人名、机构名、地名等专名 | 按相应名称规范处理；可以纳入主题词表，也可以由独立名称规范文件管理 |

这些类别及其条件见[标准 §6.6.1–§6.6.7](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)。

## 概念对应

> **【学习检查｜作者归纳】** 比较两个名称前，先问它们是否确实表示同一个概念。

例如，“备份活动”和“备份副本”如果分别表示活动与产物，就不是从中选一个首选名的问题，而是需要分别处理两个概念。名称看起来相近，不足以建立等价关系。

## 语言形式

> **【语言范围｜英语词形规则】**

Z39.19 还讨论名词和名词短语、单复数、大小写等形式。比如，英语可数名词通常采用复数，但领域惯例可以构成例外；属性值等情形也允许使用形容词。[标准 §6.4–§6.5](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

这些规则不能直接变成“中文名称都要采用复数”或“所有条目都必须是名词”。学习时需要分别识别：

- 可以借鉴的控制原则，如表达一致、依据明确。
- 依赖具体语言的词形规则。
- 依赖领域和用途的例外。

## 依据记录

选定形式以后，还需要留下依据，让后续维护者知道为什么采用它。标准要求记录首选形式的依据，变体形式的来源也可以记录。[标准 §6.6](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

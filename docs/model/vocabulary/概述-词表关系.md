# 词表关系

理解词表的结构以后，需要进一步区分等价、层级、相关三类关系，以及它们与四种词表结构的对应。结构比较见[词表结构与组织](概述-词表结构与组织.md)。

## 三类关系

> **【关系分类｜Z39.19 §8】** 这三类关系供具体结构采用，不是要求每份受控词表都同时具有三类关系。

| 关系 | 要说明什么 | 例子 |
|---|---|---|
| 等价关系 | 哪些表达可以在规定语境中作为等价入口 | 自行车／脚踏车 |
| 层级关系 | 哪些概念之间存在上位、下位联系 | 交通工具／自行车 |
| 相关关系 | 哪些概念既不等价，也不存在上下位关系，但有值得明确的语义联系 | 细胞／细胞学 |

> **【教学例子与标准例子】** 前两个是教学例子；“细胞／细胞学”是 §8.4 标准例子的中文转述。

相关关系不能仅凭两个词经常同时出现就建立。[标准 §8](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

## 层级关系

> **【类型规则｜分类法与叙词表中的层级】** 层级需要区分不同的成立条件，不能全部理解成“某类的一种”。

| 层级关系 | 判断方式 | 标准例子的中文转述 |
|---|---|---|
| 种属关系 | 下位是上位的一种 | 鸟／鹦鹉 |
| 实例关系 | 下位是该类别的一个具体实例 | 海／地中海 |
| 整体部分关系 | 下位是整体的组成部分，且满足相应条件 | 脑／脑干 |

这些关系有各自的成立条件。尤其不能把任何组成、包含或目录嵌套都直接当作层级关系。[标准 §8.3](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

## 结构对应

> **【结构比较｜Z39.19 §5.4】** 下表概括各结构的关系特点，不是共同必备关系的清单。

| 类型 | 关系方面的核心特点 |
|---|---|
| 列表 | 不显式表达词项间的语义关系 |
| 同义词环 | 组织检索时的等价表达，不要求选定首选词 |
| 分类法 | 以层级关系组织首选词 |
| 叙词表 | 结合等价、层级和相关关系，并明确表示这些联系 |

“词表是什么类型”描述整体结构；“词表采用哪些关系”解释这种结构怎样组织信息。[标准 §5.4](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

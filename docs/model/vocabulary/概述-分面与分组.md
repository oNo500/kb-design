# 分面与分组

分面、划分特征、数组、节点标签和概念组，分别解决概念组织中的不同问题。它们与词表结构的整体位置见[词表结构与组织](概述-词表结构与组织.md)。

## 组织职责

> **【学习范围｜组织方法与构件】** 它们不是五种并列的词表类型，也不是每份词表都必须具备的五个部分。

| 内容 | 回答什么问题 | 教学例子 |
|---|---|---|
| 分面 | 这些概念属于哪些不同的基本类别？ | 汽车是对象，驾驶员是施动者，维修是活动 |
| 划分特征 | 某个上位概念之下，按什么属性划分？ | 汽车按动力划分 |
| 数组——层级用法 | 这一划分形成了哪组同级概念？ | 柴油汽车、电动汽车组成一组 |
| 节点标签 | 用什么显示文字说明分组依据？ | “按动力” |
| 概念组 | 按某种选定标准，需要汇集哪些已有概念？ | 为汽车维护专题选出汽车、轮胎、检查等概念 |

前四行的教学关系可结合 Z39.19 §5.3.4、§8.3.5 理解；数组与概念组的模型区分还需要参考 ISO 25964 的公开材料。[Z39.19 原文](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)、[ISO 25964 Schema 说明](https://www.niso.org/schemas/iso25964/schema-intro/)

## 层级分组

> **【标准例子译述｜层级中的划分与显示】** Z39.19 §8.3.5 用汽车说明分组依据，下面只展示其中一组。

```text
汽车
  （按动力）
    柴油汽车
    电动汽车
```

- 汽车：上位概念。
- 动力：划分特征。
- 柴油汽车、电动汽车这一组：按该特征形成的同级分组。
- “按动力”显示行：节点标签，不能拿它作为标引词。

层级关系仍然是“柴油汽车是汽车的一种”。分组说明不会代替这条关系。[标准 §8.3.5](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

## 模型边界

> **【模型范围｜ISO 25964】** 这里依据公开模型说明及对应文档，不将其要求推广到所有受控词表。

上面讲的是层级数组的常见用法，不能据此概括完整的 `ThesaurusArray` 模型。公开对应文档还讨论分面组织，并将 `ThesaurusArray` 与 `ConceptGroup` 分别表示。[ISO 25964 与 SKOS 对应文档](https://groups.niso.org/higherlogic/ws/public/download/12351/Correspondence%20ISO25964-SKOSXL-MADS-2013-12-11.pdf)

概念组可以依据选定属性或用途形成，并不要求成员都是同一个上位概念的直接下位。

> **【教学例子】** 汽车、轮胎、检查可以被选入一个专题集合，但不能因此都变成“汽车”的下位概念。

## 分面对象

> **【用法区别｜词表分面与资料筛选】** 分面可以作用于不同对象。

| 作用对象 | 教学例子 |
|---|---|
| 词表中的概念 | 按对象、活动、材料等类别组织词汇 |
| 被描述的资料 | 按主题、语言、格式筛选文章 |

Z39.19 §5.3.4 都讨论了，但两者组织的对象不同。看到“分面”时，先问：这里是在组织概念，还是在筛选内容对象？[标准 §5.3.4](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

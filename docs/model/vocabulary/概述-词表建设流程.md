# 词表建设流程

词表建设把选词、名称控制、范围说明和关系组织连接起来。[首选词与名称形式](概述-首选词与名称形式.md)讨论名称的选择，本篇说明这些工作怎样共同构成建设过程。

## 适用范围

> **【学习范围｜受控词表的建设】** 主要依据 NISO Z39.19 §11.1–§11.2。涉及层级、首选词等步骤时，应按选定的词表结构采用；列表和同义词环不需要照搬完整的叙词表结构。

## 建设主线

> **【学习框架｜作者归纳】** 以下是便于理解的工作顺序，不是标准规定的固定阶段；实际建设中需要反复往返。

| 工作 | 需要解决的问题 |
|---|---|
| 明确用途与范围 | 服务哪些资料和用户？核心领域是什么？需要多细？ |
| 调查已有词表 | 是否已有可使用或借鉴的词与关系？ |
| 选择结构与显示方式 | 需要列表、同义词环、分类法还是叙词表？如何呈现？ |
| 收集候选词 | 从文献、组织用法和用户表达中收集什么？ |
| 核验词与组织关系 | 含义是否明确？名称是否合适？关系是否成立？ |
| 建立记录 | 怎样保存来源、说明、关系和变更信息？ |
| 实际试用与修订 | 能否一致标引资料？用户能否找到所需内容？ |

标准建议先调查已有词表，并尽可能在收集候选词之前确定结构和显示方式；收录前需要核验范围、形式及关系。[标准 §11.1.1–§11.1.5](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

## 建设方法

> **【标准方法｜§11.1.3】**

| 方法 | 起点与做法 |
|---|---|
| 委员会方法 | 领域专家与词表专家共同确定词和关系，可自上而下或自下而上组织 |
| 经验方法中的演绎方式 | 先从资料收集足够的词，再集中审查、组织和控制 |
| 经验方法中的归纳方式 | 随资料处理逐步发现词，从一开始就进行控制和组织 |
| 混合使用 | 在不同阶段组合方法，重新检查早期判断 |

这里“演绎”“归纳”对应标准在本节中的具体用法。标准允许混合使用这些方法，并要求随着经验积累修订早期决定。[标准 §11.1.3](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

## 候选与收录

候选词是尚未完成接受程序的提议，需要明确标记。自动抽取、使用频率和查询记录可以帮助发现候选，但不能代替含义和关系判断。[标准 §11.1.3.4、§11.1.6](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

> **【教学例子｜自拟】** 从资料中发现“自行车”“脚踏车”“山地自行车”后，仍需要分别核对以下问题。

- 前两个名称是否在当前范围内表示同一概念。
- “山地自行车”与“自行车”是否成立上下位关系。
- 当前用途是否需要细到这一层。

抽取结果提供了待判断的材料。

## 组织问题

> **【教学应用｜作者归纳】** 下面联系知识体系组织中的缺口、重复与混淆问题，不把它当作标准中的固定分类。

| 发现的现象 | 需要进一步判断 |
|---|---|
| 一份重要资料找不到合适的词 | 缺少概念、缺少名称入口，还是资料超出了词表范围？ |
| 两个条目看起来重复 | 是同一概念的不同名称，还是两个范围相近的概念？ |
| 不同人反复选用不同词 | 范围说明不清、名称有歧义，还是标引理解不同？ |
| 层级中似乎缺少中间概念 | 是否有依据补足？新增概念是否具有独立用途？ |
| 一个词从未被使用 | 是不需要，还是具有组织层级和未来标引的价值？ |

标准允许为完善层级收录尚未用于标引、但具有潜在标引价值的词。因此，不能仅按使用次数判断是否删除。[标准 §11.1.8](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

同时要区分：词表的缺口，是表达和组织能力的缺口；资料库的缺口，是内容覆盖的缺口。两者可以相互提示，但不能互相替代证明。

## 效果验证

建成记录并不等于建设有效。标准建议检查词表本身，也实际尝试标引和检索；让多人标引相同资料，可以通过分歧发现问题。[标准 §11.2](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

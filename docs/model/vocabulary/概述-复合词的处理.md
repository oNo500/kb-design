# 复合词的处理

一个表达应该整体收入词表，还是用几个独立的词组合表示？[先组与后组](概述-先组与后组.md)说明组合时机，本篇进一步讨论复合词的保留与拆分。

## 适用范围

> **【学习范围｜Z39.19 的词汇控制规则】** 本篇依据标准第 7 节的 compound terms，沿用“复合词”的说法。它讨论受控表达的处理，不是在讲中文分词算法。英语词形方面的规则也不能直接套用到中文。

## 整体含义

“名称由几个词组成”和“表达几个概念”需要分别判断。

一个名称即使包含多个词，也可能已经作为一个稳定的整体使用。拆分时需要检查：原来的含义是否仍能准确表达，组成部分能否独立使用，检索会不会产生错误组合。[标准 §7.2–§7.3](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

## 保留依据

> **【标准规则归纳｜§7.5】** 标准列出以下七类保留依据。表中英文例子来自标准。

| 保留依据 | 标准例子 |
|---|---|
| 拆开会歧义或丢失含义 | data dictionaries |
| 某个部分过于含糊，或不适合独立收入该词表 | first aid |
| 整体含义已不是各部分原义相加 | trade winds |
| 修饰部分是比喻 | tree structures |
| 表面像某类事物，实际上并不属于该类 | paper flowers |
| 是专名，或包含专名成分 | United Nations |
| 已在日常或专业用法中形成稳定的整体概念 | data processing |

不能因为一个表达“可以拆成几个字词”，就认定它适合拆开标引。[标准 §7.5](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

## 拆分条件

> **【标准建议｜§7.6】** 标准明确指出，拆分建议不能在所有情况下机械执行。以下是三组主要判断，每组都有相反的保留情形。

| 判断方向 | 考虑拆分 | 对照的保留情况 |
|---|---|---|
| 部分或性质与其所属对象 | “土壤的酸度”用“土壤＋酸度”表示 | “酸性土壤”整体表示一类土壤 |
| 动作与动作作用的对象 | “纺织品印花”用“纺织品＋印花”表示 | “印花纺织品”整体表示一类产品 |
| 动作与动作执行者 | “鸟类迁徙”用“鸟类＋迁徙”表示 | “舞鞋”整体表示一类物品 |

表格是标准例子的中文译述；“＋”只表示共同使用组成部分，不是正式关系标示。[标准 §7.6](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

## 语义区别

> **【教学解释｜根据上述例子】**

“土壤的酸度”关注的是一种性质，并说明性质属于谁。

“酸性土壤”关注的是一类土壤，并用性质限定其类别。

它们虽然包含相近的内容，表达的对象却不同。拆分决定因此要依据含义，不能只看名称长短。

## 学习检查

> **【学习检查｜作者归纳】** 这不是标准规定的固定流程。

1. 整体到底指什么？
2. 拆开会不会丢失含义或形成错误组合？
3. 各部分是否适合独立收入词表？
4. 专业文献和使用者是否把整体当作稳定表达？
5. 当前需要怎样支持标引、浏览和检索？

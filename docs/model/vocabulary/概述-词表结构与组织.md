# 词表结构与组织

理解词表的结构，需要先完整比较列表、同义词环、分类法和叙词表各自包含什么、表达哪些关系，再学习组织方法和分组构件怎样与具体结构配合。

## 结构类型

> **【结构类型｜NISO Z39.19 §5.4】** 本节比较四种结构，不把其中一类的构成作为其他类型的共同要求。表中的例子为教学说明。

| 类型 | 包含什么 | 表达什么关系 | 教学例子 |
|---|---|---|---|
| 列表（list） | 明确列出的一组词项，按字顺或其他逻辑排列 | 列表本身不表达词项之间的语义关系 | 文本、图像、声音 |
| 同义词环（synonym ring） | 一组在检索中被视为等价的表达 | 检索等价关系；不要求指定首选词 | 搜索“脚踏车”时，也检索使用“自行车”的内容 |
| 分类法（taxonomy） | 表达概念的首选词，组织为层级或多层级结构 | 上位、下位关系；可以有多个上位 | 交通工具 → 自行车 → 山地自行车 |
| 叙词表（thesaurus） | 概念、表达概念的词，以及明确组织的关系 | 表达形式之间的等价，以及概念之间的层级和相关关系 | 一个主题有首选词、其他入口，并与更宽、更窄或相关主题相连 |

前三行依据 Z39.19 的结构说明；叙词表的“概念—词—关系”表述结合 ISO 25964 的官方说明。这里概括的是结构，不是四种词表共同使用的一套必填字段。[Z39.19 §5.4](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)、[ISO 25964 官方说明](https://www.niso.org/schemas/iso25964)

## 方法与构件

> **【组织方法与构件｜与四种结构分开学习】** 以下内容分别涉及组织、分组、显示和组合。它们不是与列表、分类法、叙词表并列的词表类型，也不是每种词表都必须具有的部件。

这一组不只是“分面、数组、概念组”三个名称，还需要把划分依据、显示方式和组合方式讲清楚。

| 内容 | 属于什么 | 具体作用 |
|---|---|---|
| 分面分析 | 组织方法 | 按概念的内在类别分析和组织词汇，例如区分对象、活动、材料 |
| 划分特征 | 划分依据 | 说明某个上位概念的下位概念按什么属性区分，例如汽车“按动力”划分 |
| 数组 | 同级概念的分组 | 将同一划分特征下的同级概念组织成组 |
| 节点标签 | 显示说明 | 显示“按动力”等分组依据；它本身不是用于标引的概念 |
| 概念组 | 按用途形成的集合 | 选出一批已有概念，可以跨分支，而不改变它们原有的关系 |
| 先组与后组 | 组合方式 | 区分在建表或标引时预先组合表达，还是在检索时组合概念 |

这些概念分别涉及 NISO 指南的分面分析、复合表达及节点标签说明，以及 ISO 25964 的公开模型。[Z39.19 §5.3.4、§7、§8.3.5](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)、[ISO 25964 模型入口](https://www.niso.org/schemas/iso25964)

## 分组的区别

> **【比较说明｜不同层次的对象】** 列表是一种词表结构；数组与概念组在这里作为组织概念的构件比较，不构成三种同级词表类型。

- 列表：一种词表结构，本身可以独立提供允许值。
- 数组：围绕某个上位概念，按划分特征组织其同级下位概念。
- 概念组：为了某个用途选出概念，不要求它们拥有同一个上位概念。

## 学习顺序

> **【学习框架｜作者归纳】** 以下顺序用于组织学习，不是标准规定的实施步骤，也不表示四种结构必须依次升级。

先完整比较四种词表各自包含什么、表达哪些关系；再学习组织方法和构件如何与具体结构配合。每一种结构都分别讨论定义、构成、关系、用途和适用条件。

此前的共同基础见[词表入门](概述-词表入门.md)、[词汇控制原则](概述-词汇控制原则.md)和[选词依据](概述-选词依据.md)。

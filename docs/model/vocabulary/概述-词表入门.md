# 词表入门

本文依据 ANSI/NISO Z39.19-2005 (R2010) 的 §1、§2 和 §5.1–5.2，介绍它要解决的问题，以及词表怎样与内容发生联系。

> **【通用基础｜Z39.19 范围内】** 目的、范围和基本概念是本标准的共同基础；是否采用层级、首选词或标引，还要看具体结构。

## 词表的目的

词表的目的是组织信息，使描述一致、内容可找到。§5.1 将其用途分为五项，下面是解释性转述。

| 用途 | 含义 |
|---|---|
| 表达转换 | 把作者、标引者和检索者的自然语言转换为可共同使用的词汇 |
| 一致性 | 统一词的形式及使用方式 |
| 关系表达 | 明确词之间的语义联系 |
| 标识与浏览 | 提供清晰的组织结构，帮助逐层查找 |
| 检索 | 帮助定位所需内容 |

这里的“转换”主要指自然表达与受控表达之间的转换，不专指中英文翻译。[标准 §1、§5.1](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

## 标准的范围

这份标准指导词表的建设与管理，覆盖词的选择、形式、关系、显示、建设、测试和维护，讨论列表、同义词环、分类法和叙词表。它主要面向单语词表，特别参照英语。

它不提供逐篇内容的具体标引操作指南，也不覆盖本体、语义网络等体系的完整设计。因此，学习这份标准能够掌握词表的重要基础，但不能把它当成全部知识组织方法的总规范。[标准 §2](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

## 基本概念

§5.2 实际依次讨论的是词（term）、内容对象（content object）、标引（indexing）。词用来表达概念；标引则把选定的词用于描述内容对象。[标准 §5.2](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

先理解“词—内容对象—标引”的联系，再学习选词、关系和结构，能够分清词表中组织的表达与实际需要查找的内容。

## 教学例子

> **【教学例子｜以叙词表的标引场景为例】** 本例采用首选表达和检索入口，不适用于仅组织等价检索、不参与标引的同义词环。

假设有两篇文章：《自行车维护》和《脚踏车维修》。下面用这个例子串起各个概念。

| 对象或动作 | 在例子中是什么 |
|---|---|
| 概念 | 自行车这种交通工具所指的意义 |
| 词 | “自行车”“脚踏车”这两种表达 |
| 内容对象 | 两篇需要被组织和查找的文章 |
| 词表中的约定 | 选“自行车”作为首选表达，让“脚踏车”成为对应入口 |
| 标引 | 使用选定的词“自行车”描述这两篇文章涉及的主题 |
| 检索 | 用户搜索“脚踏车”时，通过对应入口查找相关内容 |

> **【通用基础｜Z39.19 范围内】** 以下回到词与概念的区别；末段的“标引—检索”使用链限于参与标引的词表。

这里，“概念”与“词”的区别很重要：两个叫法不必是两个概念；两篇文章也不因此成为两个词表条目。

词表先组织可用于描述的词及其联系；标引把它们与实际内容连接起来；浏览和检索再利用这些信息。选词、关系、结构及维护，都建立在这条联系之上。

# 主题词表

本主题集中解释词表是什么、如何组织和使用，以及 kb-design 的具体选择。初次阅读从[词表总览](概述-词表.md)开始；需要修改正式数据时，再进入现行设计。

## 学习主线

先通过总览建立整体认识，再按问题选择专题。以下入口对应总览的不同部分。

| 阶段 | 需要理解的问题 | 总览入口 |
|---|---|---|
| 用途与构成 | 词表解决什么问题，需要掌握哪些基本概念？ | [词表的作用](概述-词表.md#词表的作用)、[知识范围](概述-词表.md#知识范围) |
| 结构与关系 | 列表、分类法和叙词表有什么区别，概念关系处于什么位置？ | [结构类型](概述-词表.md#结构类型)、[知识范围](概述-词表.md#知识范围) |
| 分组与组合 | 分面、数组、节点标签、概念组以及先组后组各自做什么？ | [组织方法](概述-词表.md#组织方法) |
| 使用与维护 | 怎样标引和检索，怎样判断词表是否好用，变更怎样影响旧内容？ | [知识范围](概述-词表.md#知识范围)、[建设与维护](概述-词表.md#建设与维护) |
| 互操作与扩展 | 映射、SKOS、本体与知识图谱分别处于什么位置？ | [互操作与扩展](概述-词表.md#互操作与扩展) |

以下专题解释各自的问题。部分旧文存在项目用法过时或通用表述过强的情况，已列入[内容复核记录](../../../work/reviews/2026-09-12-vocabulary-content-review.md)；总览的学习顺序不表示这些旧段落已经修订完成。

| 问题 | 专题 | 阅读重点 |
|---|---|---|
| 概念与名称 | [受控词表](概念-受控词表.md) | 结构和关系的基本区分；项目字段另查设计 |
| 层级与分组 | [词表的层级](概念-词表的层级.md) | 数组、节点标签与多上位；层级类型的覆盖仍需补充 |
| 分面分析 | [分面](概念-分面.md) | 区分概念分类与资料筛选；固定建设顺序及媒介结论待复核 |

| 建设过程 | [词表的建设与维护](概念-词表的建设与维护.md) | 收录依据、记录与变更；通用方法和本地状态分别理解 |
| 新主题处理 | [新主题的分类](概念-新主题的分类.md) | 理论问题入口；旧字段、计数及固定处理流程待重写 |
| 跨表关联 | [词表映射](概念-词表映射.md) | 比较概念范围，区分映射和结构复制 |

## 现行设计

项目规则由现行设计及具体采纳决定规定，概念解释不批准字段、状态或关系。

| 文章 | 规定内容 |
|---|---|
| [主题词表设计](设计-主题词表.md) | 覆盖范围、概念记录、语言依据、生命周期与生成路径 |
| [层级结构](设计-层级结构.md) | 学科结构、多上位关系、数组及结构来源 |

正式数据是 [topics.yaml](../../../data/vocab/topics.yaml)。修改须从主题生成输入与核心实现开始，再按设计重建和核对；不直接编辑生成结果。内容怎样引用主题，见[内容模型](../content/设计-内容模型.md)。

## 标准与资料

- [ANSI/NISO Z39.19 受控词表指南](阅读-ANSI-NISO%20Z39.19%20受控词表指南.md)：结构、建设、评价与维护的阅读记录。
- [ISO 25964 叙词表标准](阅读-ISO%2025964%20叙词表标准.md)：标准范围、已读定义及公开模型材料。
- [GB/T 13745 学科分类清单](阅读-GB-T%2013745-2009%20学科分类清单.md)：本库相关学科的来源条目。
- [SKOS Primer](https://www.w3.org/TR/skos-primer/)：概念、标签、关系、标引、集合和映射的表达示例。

阅读记录各自说明核对范围。具体派生、映射和项目采纳仍需各自的依据。

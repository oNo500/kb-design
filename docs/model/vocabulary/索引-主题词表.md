# 主题词表

本主题收录词表的整体设计、专题规范、解释及标准阅读。理解目标方案从[词表整体设计](设计-词表整体设计.md)开始；学习基本概念从[词表总览](概述-词表.md)开始；维护现有数据与工具进入[词表实践](../../practices/vocabulary/索引-词表实践.md)。

## 目标设计

六篇共同说明一套设计：整体篇串联方案，专题展开复杂问题，数据规范集中字段与约束，示例辅助理解。

| 职责 | 文档 | 查阅内容 |
|---|---|---|
| 完整方案 | [词表整体设计](设计-词表整体设计.md) | 用途、范围、对象、整合、组织、全程衔接及验收 |
| 语言专题 | [多语言词表](设计-多语言词表.md) | 语言策略、概念对应、翻译、复用、匹配与显示 |
| 维护专题 | [词表维护](设计-词表维护.md) | 职责、收录、编辑、来源更新、冲突与退出 |
| 版本专题 | [词表版本](../../governance/maintenance/设计-词表版本.md) | 版本固定、引用、历史读取、发布与回退 |
| 数据规范 | [词表数据规范](设计-词表数据规范.md) | 资源字段、关系约束、管理记录及统一校验 |
| 解释示例 | [词表资源与字段](设计-词表资源与字段.md) | 资源、类型、属性、对象关系及 Turtle 实例 |

首次通读沿整体篇的[处理流程](设计-词表整体设计.md#处理流程)进入专题；需要准确字段时查数据规范，需要理解表示时查示例。每条细则由相应正文完整维护，采纳过程通过决定记录追溯。设计未决事项统一见[待定事项](设计-词表整体设计.md#待定事项)。

## 学习主线

先通过总览建立整体认识，再按问题选择专题。以下入口对应总览的不同部分。

| 阶段 | 需要理解的问题 | 总览入口 |
|---|---|---|
| 用途与构成 | 词表解决什么问题，需要掌握哪些基本概念？ | [词表的作用](概述-词表.md#词表的作用)、[知识范围](概述-词表.md#知识范围) |
| 结构与关系 | 列表、分类法和叙词表有什么区别，概念关系处于什么位置？ | [结构类型](概述-词表.md#结构类型)、[知识范围](概述-词表.md#知识范围) |
| 分组与组合 | 分面、数组、节点标签、概念组以及先组后组各自做什么？ | [组织方法](概述-词表.md#组织方法) |
| 使用与维护 | 怎样标引和检索，怎样判断词表是否好用，变更怎样影响旧内容？ | [知识范围](概述-词表.md#知识范围)、[建设与维护](概述-词表.md#建设与维护) |
| 互操作与扩展 | 映射、SKOS、本体与知识图谱分别处于什么位置？ | [互操作与扩展](概述-词表.md#互操作与扩展) |

## 标准与资料

- [ANSI/NISO Z39.19 受控词表指南](阅读-ANSI-NISO%20Z39.19%20受控词表指南.md)：结构、建设、评价与维护的阅读记录。
- [ISO 25964 叙词表标准](阅读-ISO%2025964%20叙词表标准.md)：标准范围、已读定义及公开模型材料。
- [GB/T 13745 学科分类清单](阅读-GB-T%2013745-2009%20学科分类清单.md)：本库相关学科的来源条目。
- [SKOS Primer](https://www.w3.org/TR/skos-primer/)：概念、标签、关系、标引、集合和映射的表达示例。

阅读记录各自说明核对范围。具体派生、映射和项目采纳仍需各自的依据。

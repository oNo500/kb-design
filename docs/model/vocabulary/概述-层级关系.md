# 层级关系

层级关系说明上位与下位怎样联系。三类关系的总体区别见[词表关系](概述-词表关系.md)，首选词与非首选词的对应见[等价关系](概述-等价关系.md)。

## 成立条件

> **【类型规则｜分类法与叙词表中的层级】** “上位—下位”不能仅凭目录位置决定。以下不是所有受控词表的共同必备结构。

Z39.19 §8.3 区分三种逻辑情况。

| 类型 | 成立条件 | 标准例子的中文转述 |
|---|---|---|
| 种属关系（generic） | 下位类别的成员都属于上位类别 | 鸟／鹦鹉 |
| 实例关系（instance） | 下位是上位类别的一个具体实例 | 海／地中海 |
| 整体部分关系（whole-part） | 下位是整体的固有组成部分，并满足相应条件 | 脑／脑干 |

[标准 §8.3.1–§8.3.3](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

三者的区别是：

- 鹦鹉是一种鸟。
- 地中海是一个具体的海，不是海的一种类别。
- 脑干是脑的一部分，不是一种脑。

## 关系标示

> **【关系标示｜采用 BT／NT 表达时】** 两个方向的标示不同，但需要相互对应。

| 标示 | 方向 |
|---|---|
| BT（Broader Term） | 从下位指向上位 |
| NT（Narrower Term） | 从上位指向下位 |

> **【标准例子译述｜Z39.19 §8.3】**

```text
哺乳动物  BT  脊椎动物
脊椎动物  NT  哺乳动物
```

这是一对互反关系：从两个方向表达同一层级联系。[标准 §8.3](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

## 判断边界

> **【规则范围｜Z39.19 的层级判据】** 不能把“有联系”都当成层级关系。以下例子与限制来自原文。

- 研究对象不是学科的下位类别。标准指出，解剖学与中枢神经系统分别是学科和身体组成部分，不能因此建立层级关系。
- 不是任何部件都能直接挂成下位。标准以化油器也用于其他机器为例，要求汽车与化油器采用相关关系，而非层级关系。
- 多上位不是第四种层级语义。它表示一个概念具有多个上位联系；每条联系仍须分别判断是否成立。

[标准 §8.3、§8.3.3.2、§8.3.4](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

看到一条上下位关系，先问：它表达“一种”“一个实例”，还是“一部分”？依据是什么？不能只看它被放在哪个目录下面。

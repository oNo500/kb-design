# 层级关系

层级关系表达上位与下位之间的含义联系。分类法与叙词表会使用这种结构；目录中相邻、同级或缩进的词，不一定已经成立概念层级。

## 成立条件

ANSI/NISO Z39.19 §8.3 区分三种情况。比较的两端须能按所指概念的基本类别作逻辑判断，不能只看名称。

| 类型 | 怎样理解 | 标准例子的中文转述 |
|---|---|---|
| 种属 | 下位这一类的成员都属于上位 | 仙人掌属于多肉植物；不能因为常见于沙漠就把所有仙人掌归为沙漠植物 |
| 实例 | 下位是一般类别的一个具体实例 | 阿尔卑斯山属于山地区域的具体实例，不是山地区域的一种类别 |
| 整体部分 | 部分在概念意义上内在地包含于整体，并符合该类关系的条件 | 脑属于中枢神经系统；一般部件与任意可装配整体不能直接照搬 |

学科和研究对象是不同类型的概念。标准以解剖学与中枢神经系统为例，说明研究联系不能独自证明上下位。[标准 §8.3–§8.3.3](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

## 关系标示

BT 从下位指向上位，NT 从上位指向下位；它们是同一层级联系的两个方向。需要区分类型时，标准给出 BTG／NTG、BTI／NTI、BTP／NTP。采用这些标示不等于自动取得一套同名 RDF 属性。

```text
哺乳动物  BT  脊椎动物
脊椎动物  NT  哺乳动物
```

## 多上位关系

一个概念可以有多个有依据的上位联系。多上位不是第四种关系语义，每条边仍要分别判断。

标准的例子包括：钢琴具有两个种属上位；生物化学具有两个整体部分方向的上位；头骨分别通过种属和整体部分联系到骨与头。因此，不能仅按父节点数量判断是否合法。[标准 §8.3.4](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

## 判断边界

§8.3.3.2 以化油器也用于汽车之外的机器为例，要求汽车与化油器采用相关关系；§8.3.4 同时讨论有逻辑依据的多上位。必须连同概念范围和具体例子理解，不能把两个条款压成“所有多个整体都可以”或“所有多个整体都不可以”。

名称相似、共同出现、用途联系、研究联系及目录位置都不足以独自建立层级。若来源只给出 BT／NT，保留原关系，不凭名字补猜它是哪种细分类；无法核定的具体联系仍需依据。[标准 §8.3、§8.3.3.2–§8.3.4](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

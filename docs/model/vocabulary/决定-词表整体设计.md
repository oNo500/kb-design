|---|---|
| 来源整合 | 统一收录、按需整合；保留独立来源快照与身份，具体合并和本地概念建立仍须有相应判断 |

| 标准采用 | 以 ISO 25964 核对业务对象和条件，以 RDF／SKOS／SKOS-XL 表示；按用途采用可选结构，记录未投影信息 |
| 名称与版本 | 概念身份、名称身份和文字版本分开；保留来源名称身份，无来源身份时一次性登记 UUIDv4 URI；修订同一记录可保持身份 |
| 映射与应用 | 选择性直接映射；保存版本、用途、方向、组合含义、依据及复核条件，不自动中转或改写笔记 |
| 来源更新 | 三方值比较之外，按明确依赖生成本次变化的受影响清单；译文保留与新版适用性分别处理 |
| 规则归属 | 整体选择、字段表示、运行合同、维护、翻译和术语准入各有唯一职责位置，避免独立维护重复规则 |

## 译文规则

英文文字变化本身不触发自动重译或一律退出旧译文。定义或范围变化导致适用性未确定时，保留原记录并在展示中明确待复核；已有审查结论确认失效时，退出当前有效名称，保留历史。原概念身份退出时，不按同名把译文迁给新概念。

该选择取代[词表维护设计](设计-词表维护.md)中“英文已变的条目不沿用旧译文”的目标规则；历史实现事实不改写。具体条件的唯一维护位置为[中文标签的增量同步](设计-中文标签.md#增量同步)。旧逐项采纳接口的上下文校验不因本决定放宽。

## 实施边界

本次采纳不改变已批准的来源范围、领域挂接和正式记录，不批准具体概念合并、译名或映射值；分面、划分特征及手工概念组的其他提案不随之生效。正式内容消费者、查询日志、复核义务、外部 vault 写入及发版仍按各自决定执行。

SKOS-XL 名称登记、映射记录和受影响清单需要实施及迁移验收。采纳时的展示复用代码仍会在 `@en` 首选标签变化时以 `english_changed` 排除旧译文；保留旧译文及适用性复核的目标规则尚未完整接入。文档采纳不表示该差异已经修复。

材料依据及缺页限制见[设计依据](设计-词表资源与字段.md#依据与限制)。本决定不宣称完整 ISO 符合性或无损转换。

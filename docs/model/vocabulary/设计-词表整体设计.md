# 词表整体设计

综合词表用于知识库的主题标引、浏览和检索。它统一收录选定来源的概念，按需要建立对应和本地组织，并保留名称、来源及历史。本篇说明完整方案；语言、维护和版本的复杂规则由专题展开，字段与校验集中在数据规范。

## 用途与范围

词表表达主题概念及其组织方式。内容单元、普通实体、正式术语和应用界面分别遵循各自模型；导入名称不自动建立这些对象或改变其归属。

范围声明明确用途、主题边界、概念粒度、适用语言和排除项。概念收录、浏览分组和实际使用分别判断；缺名、未分组或暂未使用本身不是删除依据。具体来源、概念和范围按相应权限采用。

本方案依据[整体采纳](决定-词表整体设计.md)、[维护约束](决定-词表维护约束.md)、[多语言采纳](决定-多语言词表.md)及后续[规则修订](决定-词表规则修订.md)。这些决定确定通用要求，具体名称、关系和映射仍须有采用依据。

## 标准采用

| 依据 | 采用范围 |
|---|---|
| ISO 25964 的公开模型与已核材料 | 核对概念、名称、组织、维护及互操作的业务对象和条件 |
| ANSI/NISO Z39.19 §8.3–§8.3.4 | 自有分类法与叙词表的层级判据 |
| RDF、SKOS、SKOS-XL | 资源身份、概念关系、集合与独立名称记录 |
| Dublin Core、PROV-O | 描述、来源和派生依据 |
| IFLA 多语言指南、BCP 47 | 跨语言概念对应、语言标签与匹配 |
| Turtle、SHACL | RDF 序列化与明确采用的约束校验 |

标准定义表示与方法，项目按用途选择可选能力，并说明理由和适用范围。具体规则随正文引用条款，全套材料的核读范围见[标准依据](#标准依据)。

## 对象体系

本项目用一个自有 ConceptScheme 标识综合词表的收录范围，形成一致的范围声明和交付；来源体系及元数据独立保留。SKOS 允许多体系表示，单一自有体系是项目选择。

| 对象 | 职责 |
|---|---|
| 概念体系 | 说明词表的范围、成员和指定顶层 |
| 概念 | 表达含义，连接名称及概念关系 |
| 名称 | 用独立的 SKOS-XL 记录保存文字、语言及可追溯身份 |
| 集合 | 按用途组织已有成员，需要时保存顺序；集合身份与概念身份分开 |
| 说明与管理记录 | 保存定义、范围、依据、采纳、变更与发布信息，依用途附着 |

概念身份、名称身份和某一版本的文字分别识别。正式术语仍由[术语设计](../terminology/设计-术语.md)规定准入与编辑权，采用 XL 不另建一份术语库。对象表示见[数据规范](设计-词表数据规范.md)，RDF 与 Turtle 例解见[资源与字段](设计-词表资源与字段.md)。

## 数据分层

来源事实、项目选择与派生结果分别保存，应用读取明确版本的数据。

| 数据 | 保存内容 | 编辑责任 |
|---|---|---|
| 来源材料 | 原件或可定位描述、取得记录、版本及完整性依据 | 新版本另存，保留已有材料及取得限制 |
| 来源词表 | 各来源的 RDF 表示、身份、原关系与转换依据 | 导入生成，来源及版本保持可区分 |
| 项目输入 | 收录选择、领域组织、本地编辑、名称登记和采纳记录 | 各编辑入口维护各自内容，保留来源原件 |
| 自有词表 | 选定概念、组织结果及依据、历史和映射记录 | 根据固定版本的来源及项目输入产生 |
| 应用产物 | 领域分图、语言展示、导航与加载记录 | 从明确的词表版本派生，应用编辑不自动取得词表效力 |

来源图、当前主图和历史图具有不同用途；校验按明确范围读取。管理记录可以独立存放，并通过对象与版本关联。各层的责任不限定批处理、增量处理或合并算法；文件与存储方式由交付合同落实。

## 整合方式

采用统一收录、按需整合。导入不以全量消重或映射为前提；对照需求出现后，再比较定义、范围、关系和用途。

| 情形 | 处理 |
|---|---|
| 原样采用来源概念 | 含义不变时复用来源身份，保留来源版本及具体值依据 |
| 同名但含义未确定 | 保留独立身份，通过来源或范围帮助区分 |
| 对应已明确但无需合并 | 建立有依据的映射，双方记录保持独立 |
| 需要本地概念或含义与来源不同 | 经具体采纳建立本地概念，保存与来源的关系，不改写来源图 |
| 已有概念需要合并或拆分 | 保存旧身份、理由和后继对象，按[退出规则](设计-词表维护.md#概念退出)处理旧引用 |

字符串相似只提供线索；拼写或显示变化不自动产生新概念。一个自有词表不意味着所有来源已经具有相同结构，来源标签等价也不能自动推出跨来源概念同一。

## 关系与导航

概念关系表达含义，来源结构保存原组织方式，集合提供浏览或交付范围。应用可以共同展示，数据中仍分别维护。

| 组织方式 | 成立条件与边界 |
|---|---|
| 上下位关系 | 按 NISO §8.3 核对种属、实例、整体部分及多上位；判据见[数据规范](设计-词表数据规范.md#层级判据)，不由目录位置或研究对象推断 |
| 相关关系 | 有明确语义联系和检索作用；共现、共同上位及同级位置不足以自动建立 |
| 来源目录与枚举 | 保存节点、成员、顺序及原关系类型；可浏览不等于成立概念层级 |
| 领域或专题集合 | 成员有纳入依据，可以跨分支；集合成员关系不生成 `broader` |
| 数组及节点标签 | 保存划分依据、上层连接、成员及顺序；节点标签不成为可标引概念 |

来源复制与本地分析按[分层决定](决定-原样复制与本地分析分层.md)处理。新增或修订挂接须说明语义依据；组织配置或内容哈希只能定位选择，不能证明上下位成立。复核发现关系只适合导航时提出具体调整，不批量推翻既有记录。

### 用途与验收

来源已有组织信息按保留规则处理。本地新增组织先明确用途，再采用现有结构；改善浏览或维护可以构成理由，不要求证明其他方法都无法得到相同成员。

| 用法 | 需要明确的内容 |
|---|---|
| 分面分类 | 分类对象、外部类别及版本、适用范围、逐项归属、多解和无法归类的处理；内容属性不自动成为概念分面 |
| 划分特征数组 | 上位及完整的直接下位分析范围、来源版本、属性依据、判据和未归组成员；数组只组织已有下位概念，不改变它们的身份和概念关系 |
| 手工概念组 | 具体用途、成员纳入与移除依据，以及与派生集合的区别；同一概念可被多个组引用 |

名称准入与成员判断分别核对。普通浏览组验证成员依据、范围、顺序和实际展示；需要评估自动分类或检索的误收、漏收时，再建立独立人工判断样本。交付按对应 `Application Profile` 核对，不把检索实验设为所有分组的共同前置。

具体分类、划分特征及成员归属依现行准入与决策权确定；通用表示不批准具体值。类型、身份和成员的表示见[集合字段](设计-词表数据规范.md#集合字段)。

来源的数组和概念组保留原组织信息；通用集合视图未投影的内容应有明确去向。具体表示及边界见[分组扩展](设计-词表数据规范.md#分组扩展)。

## 多语言组织

同一概念可有不同语言的名称，显示语言变化不复制概念身份和关系。含义不能对应时保留差异，再按定义、范围与用途判断独立概念或映射。

来源语言保留、输出范围、翻译覆盖和显示选择分别确定。允许缺译，所选翻译源语言不天然取得概念裁决权。完整规则见[多语言词表](设计-多语言词表.md)。

## 映射与应用

采用选择性直接映射，对实际需要的两端建立有依据的对应，双方记录可继续独立。浏览参照、查询转换和标引转换分别确定用途；属性的对称性、传递性不自动授予反向或中转使用许可。

自有映射目前采用单个概念之间的简单关系。来源组合保留原表示及条件，复杂交换方案的状态见[待定事项](#待定事项)。映射记录、版本、方向与消费限制统一见[映射合同](设计-词表数据规范.md#映射记录)。全量映射不是词表可用的前提；是否建立映射中心另按覆盖、质量与用途决定。

## 处理流程

下表串联从收录到交付的过程。各环节产生的记录进入同一套数据合同，生成或校验结果不替代具体采用决定。

| 环节 | 形成的结果 | 详细规则 |
|---|---|---|
| 范围确定 | 明确用途、来源、语言、收录与排除依据 | 本篇范围与整合选择、具体范围决定 |
| 来源收录 | 固定来源描述、选定对象及转换依据 | [来源选择](设计-词表维护.md#来源选择)、[来源与依据](设计-词表数据规范.md#来源与依据) |
| 内容维护 | 已明确的字段、关系、名称身份及变更记录 | [维护设计](设计-词表维护.md)、[名称登记](设计-词表数据规范.md#名称登记) |
| 语言处理 | 有依据的译文、适用性复核和显示选择 | [翻译流程](设计-多语言词表.md#翻译流程)、[译文与复核](设计-词表数据规范.md#译文与复核) |
| 发布校验 | 对明确图范围、关系及配套记录的校验结果 | [校验范围](设计-词表数据规范.md#校验范围) |
| 版本交付 | 可定位的发布版本、相容产物及实际加载记录 | [发布与回退](../../governance/maintenance/设计-词表版本.md#发布与回退) |

来源更新重新核对本地编辑和明确依赖；受影响的译文与映射按各自适用条件复核。统一入口见[来源更新](设计-词表维护.md#来源更新)。变更原记录、采用变更、发布版本及应用加载分别留痕。

## 消费边界

应用按 `Application Profile` 声明表示、允许损失及消费行为，读取明确版本。主题标引引用概念身份；涉及历史含义、名称或译名时，按[引用方式](../../governance/maintenance/设计-词表版本.md#引用方式)同时确定版本与用法。

发布与各应用加载分别确认。转换未表达的信息可追溯，应用表示和实现限制不反向改变词表模型。现行合同、命令、实现差距与迁移安排见[词表实践](../../practices/vocabulary/索引-词表实践.md)；实践问题经记录、研究与相应决定后才能形成设计调整。

## 验收与覆盖

验收依据实际失败风险及其影响，分别证明下列结果；字段齐全或解析成功不代替语义与使用效果。

| 核对范围 | 必须能够证明 |
|---|---|
| 来源与表示 | 来源结构及具体采用可追溯，不支持的信息有明确去向 |
| 关系与语言 | 各入口使用一致规则；同文多名称、名称修订、数组、简单映射、来源组合保留及语言缺项得到正确处理 |
| 身份与版本 | 前后身份、依据和历史可对照；退出、拆分、旧引用及完整版本回退满足合同 |
| 实际消费 | 以真实内容或查询核对采用的标引、浏览或检索用途；映射方向和退出状态被正确使用 |
| 内容填充 | 用词表与有效内容关联识别尚无内容的主题；缺内容不证明主题应删除 |
| 知识覆盖 | 用明确的覆盖依据识别词表尚不能表达的知识；来源对账和分组统计不能替代这一判断 |

既有门禁已证明的机械事实不重复检查；没有真实样本的能力如实保留未验证。实施验收、数据迁移、消费者启用和治理发版分别满足其条件，设计成文不使这些状态自动生效。

## 标准依据

本设计采用标准中的表示与方法，具体规则仍须结合所列依据逐项核对。已核范围及尚未核实之处如下。

| 材料 | 可用依据 | 阅读边界 |
|---|---|---|
| [W3C SKOS／SKOS-XL](https://www.w3.org/TR/skos-reference/) | 类型、标签、说明、关系、集合、映射及名称投影 | 用于表示及一致性检查，不替代概念和名称的内容判断 |
| [ISO 25964-1 官方说明](https://www.iso.org/standard/53657.html)、[NISO 公开模型](https://www.niso.org/schemas/iso25964/schema-intro) | 业务范围、概念与术语、数组、概念组及说明结构 | 官方范围与公开交换模型已核，不等于取得全部标准正文 |
| [ISO—SKOS 对应表](https://groups.niso.org/higherlogic/ws/public/download/12351/Correspondence%20ISO25964-SKOSXL-MADS-2013-12-11.pdf) | 2013-12-11 版的对应、信息损失与扩展讨论 | 可据此定位转换问题，不证明任意数据无损往返 |
| [ANSI/NISO Z39.19-2005 (R2010)](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf) | §8.3–§8.3.4，印刷页 46–50：层级业务判据及反例 | 原文已核；本项目采用其单语分类法与叙词表层级判据，不等于已核全部 ISO 条款 |
| [IFLA 多语言指南](https://www.ifla.org/files/assets/hq/publications/professional-report/115.pdf) | §3.2、§3.3.6、§4 及相关术语；比较语言结构、等价、合并及映射 | 已取得官方全文并核读相关段落；不以其中旧标准编号宣称现行规范 |
| [RFC 5646](https://www.rfc-editor.org/rfc/rfc5646.html)、[RFC 4647](https://www.rfc-editor.org/rfc/rfc4647.html) | 语言标记、筛选与单项查找 | 默认语言和启用范围为项目选择，不由标签语法决定 |
| [W3C 数据发布最佳实践](https://www.w3.org/TR/dwbp/)、[SHACL](https://www.w3.org/TR/shacl/) | 版本、历史及数据校验方法 | 不据格式或工具调用宣称完整一致性、持久性或使用效果 |

既有 ISO 阅读曾参考第三方 Part 1 文本及 Part 2 预览；Part 1 的多语言正文尚未完成权威版本逐条核验，Part 2 预览缺少印刷页 79–99。完整材料情况见[ISO 阅读记录](阅读-ISO%2025964%20叙词表标准.md)。未核条款保持未核，不能据目录、摘要或实现结果补写标准要求；本设计不作完整 ISO 符合性或无损转换声明。

## 待定事项

以下事项按其影响范围保留，尚未采纳的表示不能作为正式接口。

| 事项 | 已有边界 | 尚需确定 |
|---|---|---|
| 数组连接 | 来源上层连接及组织含义保留，通用集合不自动产生概念层级 | 自有数组连接采用的标准属性、两端约束与校验；见[数组连接](设计-词表数据规范.md#数组连接) |
| 组合关系 | 自有简单映射已定义，来源组合原义保留 | 分别核对词表内复合等价与跨词表组合的成熟交换及消费方案 |
| ISO 材料 | 已核条款、公开模型与其他标准各按实际范围使用 | 未取得或未逐条核验的权威正文；材料缺口不由项目规则补造 |

标准边界的既有采纳见[规则修订](决定-词表规则修订.md#标准边界)。具体范围、名称和关系的待定事项仍由相应提案或采用记录管理。

# 词表维护约束

状态：已采纳，2026-09-19。用户审阅词表设计的四项补充建议及过时实现说明后回复“可以 更新吧”。本决定采纳设计约定，不宣称对应代码已经修复或迁移完成。

## 采用内容

| 事项 | 采用选择 | 正文职责 |
|---|---|---|
| 校验一致性 | 产生当前输出的各入口使用同一版本的适用规则，明确检查图及有限的标准推理范围；局部诊断不代替发布校验 | [资源与字段](设计-词表资源与字段.md#校验范围) |
| 版本与引用 | 区分来源、自有词表、双语展示版本；普通标引默认当前，历史含义及名称用法绑定版本 | [词表版本](../../governance/maintenance/设计-词表版本.md) |
| 概念退出 | 区分停止收录、来源退出、停用、合并和拆分；保留旧标识的历史读取，不自动重标引 | [词表维护](设计-词表维护.md#概念退出) |
| XL 编辑职责 | 导入、人工编辑和翻译共用名称身份登记；文字、角色和普通标签投影分别维护；回退不删除身份分配历史 | [名称编辑](设计-词表维护.md#名称编辑)及[名称衔接](设计-中文标签.md#名称衔接) |
| 实现说明 | 按当前代码区分已有能力与剩余缺口，撤下已过时的身份复用和归档重放待建描述 | [工程能力](../../development/设计-词表工程能力.md) |

## 规则衔接

本决定补充[整体设计采纳](决定-词表整体设计.md)，保留统一收录、按需整合、选择性直接映射、名称身份和译文复核原则。

旧版本设计中“稳定 ID 保证任何版本引用可解析、内容不需区分引用版本、词表不存在破坏性变更”的概括停止适用。日期版本格式仍可沿用；旧 YAML 数据、版本块、CHANGELOG 及历史决定不改写。只补字段不自动触发治理发版，不意味着可以原地改写已经发布的版本。

SKOS 映射冲突及 XL 约束采用 W3C 规范；检查图范围、入口一致性、引用读取及编辑职责是项目选择，不冒充 ISO 或 SHACL 为所有系统统一规定的流程。

## 实施范围

本次更新设计、索引、规则摘要及整理记录；不修改生成器、校验器、schema、来源或词表数据，也不执行发版、正式索引启用、内容迁移或外部知识库同步。名称准入、来源范围和具体语义判断的权限保持不变。

现有通用图校验及 SHACL 对 `exactMatch` 与 `broadMatch` 同端点冲突的漏报仍待修复；映射审查已具备相应检查。译文复用、旧引用读取和 XL 迁移也需分别实施及验收。文档更新不作为这些能力已经完成的证据。

旧节去向、规则职责和代码定位见[修订核对](../../../work/reviews/2026-09-19-vocabulary-design-update.json)。

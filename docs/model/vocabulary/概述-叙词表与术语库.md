# 叙词表与术语库

叙词表与术语库在概念、名称、定义和关系上有大量重叠。理解它们的联系，需要同时区分词汇体系、术语工作和保存术语数据的数据库。

## 来源范围

本文依据 ISO 官方公开条款、NISO 官方说明和 ANSI 提供的标准预览，未阅读付费标准的全部正文。仓库的数据布局不作为判断这些概念关系的依据。

文中的标准说明附有来源；两者怎样衔接、能否共享数据及其对知识体系建设的作用，标为应用判断，不作为标准直接规定。

## 对象定位

> **【标准说明｜不同对象】** “叙词表”和“术语库”并非完全同一层面的概念。

| 对象 | 权威资料中的定位 |
|---|---|
| 叙词表 | 面向信息检索组织概念、词和关系的受控词汇体系 |
| 术语工作 | 系统收集、描述、处理和呈现概念及其名称，包括分析概念关系、建立概念体系、编写定义 |
| 术语库 | 保存术语数据集合的数据库；集合由概念条目及相关元数据、文献信息组成 |

分别依据：[ISO 25964 官方说明](https://www.niso.org/standards-committees/iso-25964)、[ISO 704:2022 引言 §0.1](https://webstore.ansi.org/preview-pages/ISO/preview_ISO%2B704-2022.pdf)、[ISO 26162-3:2023 §3.1、§3.11、§3.14](https://www.iso.org/obp/ui?_escaped_fragment_=iso%3Astd%3Aiso%3A26162%3A-3%3Aed-1%3Av1%3Aen)。

术语库不能理解为“叙词表里面负责名称和定义的那一小块”。

## 概念体系

> **【标准说明｜术语工作】** ISO 704 明确把以下工作纳入术语工作。

- 识别概念及概念关系。
- 分析和组织概念领域。
- 建立概念体系。
- 定义概念。
- 为概念确定名称。

术语工作本身就会组织概念体系，并不只处理字词或翻译。该标准的主要目标是支持明确、规范的人际交流。[ISO 704:2022 引言 §0.1](https://webstore.ansi.org/preview-pages/ISO/preview_ISO%2B704-2022.pdf)

因此，不能把术语库的作用缩减为查定义、查译名，也不能仅凭“主要用途不同”，将两者的字段和能力硬切成互不相交的两份。

## 标引与检索

> **【标准说明｜叙词表】** 叙词表把概念、名称及关系用于标引和检索。

ISO 25964-1 明确面向信息检索应用，内容包括概念范围、词、等价关系、概念关系和分面分析。ISO 25964-2 又把 Terminologies 单列为第 22 章，在不同词汇体系互操作的框架下讨论。[ISO 25964 官方范围与目录](https://www.niso.org/standards-committees/iso-25964)

## 包含关系

> **【来源归纳｜关系判断】** 上述资料支持将两者视为密切相关、需要比较和互操作的体系，不支持把它们直接排成简单的上下级包含关系。

“叙词表包含术语库”不是这些来源支持的通用结论。两者可以在概念、名称、定义和关系上大量重叠，但组织目的与要求不同。

## 术语工作支持

> **【应用判断｜材料与方法的衔接】** 叙词表可以支持术语工作，也可以为术语库提供概念、名称和关系方面的材料。

| 支持方向 | 可以提供的材料 |
|---|---|
| 识别概念 | 一个领域已有的概念及组织结构 |
| 整理名称 | 首选名称、其他叫法及对应关系 |
| 分析关系 | 上下位和相关关系，辅助建立概念体系 |

这些能力与 ISO 704 所述术语工作中的概念识别、关系分析和名称管理有交集。[ISO 704:2022 引言](https://webstore.ansi.org/preview-pages/ISO/preview_ISO%2B704-2022.pdf)、[ISO 25964 官方说明](https://www.niso.org/standards-committees/iso-25964)

“可以支持”不等于“可以直接替代”。将叙词表材料用于术语库时，仍需核对概念范围、定义、名称适用条件和依据是否满足术语工作的要求。

## 数据共享

> **【设计方向｜非标准要求】** 同一批数据能否同时支持两者，可以作为设计方向研究。

例如，同一个概念的名称和定义可以共享，再分别满足术语管理与检索所需的规则。这是实现层面的选择，不是标准要求它们必须合并或必须分库。

两者可以衔接、共享材料，并支持共同的概念组织工作；共享前仍需确认概念及其适用范围一致。

## 知识组织作用

> **【应用判断｜知识体系建设】** 术语工作的概念分析与体系组织，同样是知识体系建设的重要基础，不能只把它放在分类法或叙词表之后当辅助词典。

知识体系建设可以同时利用术语工作对概念、定义和名称的分析，以及叙词表对标引和检索的支持。两者的重叠部分需要协调，具体职责和数据共享方式则应依据实际用途确定。

# 相关关系

等价关系与层级关系之外，还需要判断哪些语义联系值得在词表中明确表达。前两类关系见[等价关系](概述-等价关系.md)和[层级关系](概述-层级关系.md)。

## 成立条件

> **【类型规则｜叙词表中的常规相关关系】** 以下说明 Z39.19 §8.4 的相关关系，不是要求所有类型的词表都具备这种关系。

相关关系需要满足两个方面：

- 两个词之间既不是等价关系，也不是上下位关系。
- 它们有足够明确的语义联系，值得为标引或检索提供相互提示。

“在同一篇文章里出现过”或“感觉有联系”，本身还不够。[标准 §8.4](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

## 关系标示

> **【关系标示｜RT】** 常规相关关系使用 RT（Related Term），两个方向使用相同标示。

> **【标准例子译述】**

```text
植物学  RT  植物
植物    RT  植物学
```

植物学研究植物，但植物不是植物学的一种。因此，这里表达相关，而不是上下位。

原文还列举了多种联系，下面只是其中一些。

| 联系 | 标准例子的中文转述 |
|---|---|
| 学科与研究对象 | 植物学／植物 |
| 活动与产物 | 编织／布 |
| 原料与产品 | 小麦／面粉 |
| 被测量的对象或性质与测量工具 | 温度／温度计 |

[标准 §8.4.2](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

## 同级关系

> **【判断边界｜同级关系】** 同级不等于不能相关，也不等于必须相关。

标准 §8.4.1 区分了不同情况：

- 同级词的含义有交叠，但又能分别定义时，可以需要 RT 提示。
- 存在派生联系时，也可能需要 RT。
- 只是拥有共同上位、含义互斥的同级词，不必全部相互连接。

不能简单规定“同一个父节点下都不许相关”，也不能把同级词全部连起来。[标准 §8.4.1](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

## 表示边界

> **【表示边界｜普通 RT 与细化关系】**

RT 表示“相关”，本身不明确编码“研究”“生产”“测量”等具体方向。需要表达更精确的联系时，§8.4.4 允许细化关系标示及其互反标示，但要求清楚说明含义。[标准 §8.4.4](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

## 学习检查

> **【学习检查｜根据标准归纳】** 以下问题帮助理解判断过程，不是标准原文中的固定检查表。

准备建立相关关系时，问三件事：

1. 能否清楚说明它们具体怎样相关？
2. 这个联系能为标引或检索提供什么帮助？
3. 是否其实应该使用等价或层级关系？

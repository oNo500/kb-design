# 选词依据

既然词表要规范用词，就需要回答：凭什么决定收录和采用哪些词？选词依据（warrant）提供了判断的起点。

## 三类依据

> **【通用基础｜Z39.19 范围内】** 三类依据用于选词判断；如何采用这些词，取决于词表的具体结构与用途。

ANSI/NISO Z39.19-2005 (R2010) §5.3.5 提出三类依据。以下中文是解释性转述。[标准原文](https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)

| 依据 | 主要看什么 | 要回答的问题 |
|---|---|---|
| 文献依据（literary warrant） | 待标引的内容，以及领域词典、教材、已有词表 | 这个领域通常怎样表达这个概念？ |
| 组织依据（organizational warrant） | 使用词表的组织的需要、优先事项和偏好表达 | 组织在实际工作中采用什么说法？ |
| 用户依据（user warrant） | 用户的信息请求和实际搜索用词 | 用户会用什么词来寻找这个概念？ |

这里的“文献”不只指学术论文，还包括词表实际需要描述的内容及其相关参考资料。

## 教学例子

> **【教学例子｜叙词表的首选词选择】** 以下演示首选词及其他入口的选择，不意味着同义词环也要指定首选词。

假设要为自行车相关资料建立词表，收集到以下情况。

- 教材和技术资料普遍使用“自行车”。
- 使用词表的机构也采用“自行车”。
- 部分用户经常搜索“脚踏车”。

这些依据可以支持：选择“自行车”作为首选表达，同时保留“脚踏车”作为检索入口。这样既保持表达一致，也照顾用户的实际叫法。

这是用于说明判断过程的假设例子，不是标准原例。

## 判断边界

> **【通用基础｜Z39.19 范围内】**

三类依据可能一致，也可能冲突。它们提供判断材料，§5.3.5 并没有给出统一的票数、权重或自动选词算法。

选词必须回到内容、使用者和使用环境。不能仅因为一个词听起来专业，或在某个现成词表里出现，就直接认定它适合当前用途。

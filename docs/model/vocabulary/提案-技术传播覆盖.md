## 覆盖判据

[NCES CIP 09.0908](https://nces.ed.gov/ipeds/cipcode/cipdetail.aspx?cipid=91423&y=56) 的 `Technical and Scientific Communication` 教育专业范围包括技术写作、信息设计、受众分析和文档可用性等；[IEEE PCS 章程](https://procomm.ieee.org/wp-content/uploads/2025/03/ProComm-Constitution-Approved-March-2025-CLEAN.pdf)第一条涉及技术及专业环境中多种媒介的传播。这些材料支持比较范围，不能直接作为本地完整学科的定义或层级。

技术写作、专业传播活动和完整学科分别核对；来源中的教育专业名称不自动成为本地采用名称。产品使用信息、DITA 标准及结构化写作方法按各自对象处理，不作为扩大领域或改变内容类型的附带理由。

概念范围、来源身份、定义与关系按[整体设计](设计-词表整体设计.md#整合方式)比较；浏览入口按[关系与导航](设计-词表整体设计.md#关系与导航)处理。先判断缺少的是已有概念的展示、来源收录，还是确有尚未表达的概念，再选择表示方式。

## 方案选择

| 方案 | 适用条件与结果 |
|---|---|
| 保持现有表示 | 现有概念满足用途；继续明确有限覆盖，不因领域名称较宽就扩大收录 |
| 复用已有概念或分组 | 所需含义已经存在；按用途调整成员、来源选择或映射，分别给出依据与采纳范围 |
| 新建本地概念 | 具体含义确有需要且不能复用已有概念；另行提交名称、范围、来源对应及关系理由，不预定父项或新增顶层 |

完整学科不因用于计算语境就成为 CS2023 职业能力单元的种概念；`other-communication-studies` 也不是新增概念的默认容器。若需建立相关关系或调整 YAML 层级，按具体含义分别判断。

## 待定事项

- 明确技术传播领域需要支持的实际内容及查询，区分标引需求与浏览需求。
- 对照现有概念和来源，列明已覆盖、可复用及仍有缺口的含义；需要跨 YAML 与 RDF 对应时，单独核对身份与语义。
- 对确认的缺口选择方案，并给出涉及的具体记录、依据及影响范围；概念、名称、关系、来源范围和消费者分别取得相应决定。

本提案不预先批准完整学科节点、新顶层、中文名称、DITA 实体归属或内容类型变更。具体生成、迁移与回退核对随所选改动确定。

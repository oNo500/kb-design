# 词表总览

系统理解词表，需要先明确它的用途，再认识构成、结构和组织方法，最后理解它怎样参与检索、怎样维护，以及怎样与其他体系共同使用。

**词表的用途 → 基本构成 → 结构类型 → 组织方法 → 实际使用 → 建设维护 → 互操作与扩展。**

## 词表的作用

在知识体系的组织中，词表负责明确：采用哪些概念、这些概念叫什么，以及根据用途建立哪些关系，从而支持一致的描述、标引和检索。

“词表”这个词本身很宽泛。这里主要讨论受控词表：名称和概念经过选择，并按照明确规则持续管理。NISO 指南的范围就包含词表的内容、结构、建设、测试和维护。

## 知识范围

理解词表，需要区分以下问题及其涉及的概念。

| 学习部分 | 核心问题 | 涉及的概念 |
|---|---|---|
| 基本构成 | 一个词表条目究竟表示什么？ | 概念、名称、标识符、定义、范围注释 |
| 名称控制 | 同义、歧义、多语名称怎样处理？ | 首选名、替代名、隐藏标签、限定说明 |
| 概念关系 | 概念之间如何连接？ | 上位、下位、相关关系、多上位关系 |
| 结构类型 | 词表可以组织成什么形式？ | 列表、同义词环、分类法、叙词表 |
| 组织方法 | 怎样划分、分组和组合概念？ | 分面、划分特征、数组、节点标签、概念组、先组与后组 |
| 实际使用 | 怎样用词表描述和查找内容？ | 标引、查询匹配、检索扩展、浏览 |
| 建设维护 | 怎样收录、调整并检验词表？ | 收录依据、范围、粒度、变更、历史、效果评价 |
| 互操作 | 多份词表怎样共同使用？ | 概念映射、多语对应、交换与发布 |

这张表中的项目处于不同层次。基本构成说明词表由什么组成；结构类型说明关系怎样组织；组织方法说明怎样划分和组合；使用与维护说明词表如何发挥作用并持续变化。

## 结构类型

NISO 指南按结构区分以下四种受控词表。

| 结构 | 主要作用 |
|---|---|
| 列表 | 明确允许使用哪些值 |
| 同义词环 | 搜索一种写法时，也能找到其他等价写法对应的内容 |
| 分类法 | 用层级关系组织概念 |
| 叙词表 | 同时控制名称，并表达层级关系和相关关系 |

这组划分比较的是结构能力，不是每份词表都必须经历的升级阶段。同义词环主要用于检索；是否需要层级或相关关系，则取决于实际的组织与检索任务。

## 组织方法

分面、数组和概念组回答不同的组织问题。

- **分面**：按概念的内在类别分析和组织概念。
- **划分特征与数组**：某个上位概念之下，按什么依据划分同级概念，并将其成组。
- **节点标签**：怎样说明分组依据，而不额外建立一个用于标引的概念。
- **概念组**：为了某个用途选出一批概念，保留它们原有的关系。

这些方法可以配合使用。分面分析与层级组织可以并存，概念组也可以包含来自不同分支的概念；不能把它们与“列表、分类法、叙词表”混排成一组词表种类。

先组与后组进一步涉及组合时机：在建表或标引时预先组合表达，还是在检索时组合独立概念。组合方式会影响表达的准确性与检索的灵活性，需要结合具体语义判断。

## 互操作与扩展

理解词表内部的组织以后，再学习词表之间的映射。映射说明不同词表中的概念怎样对应；名称相同不能直接证明范围相同，确认对应也不要求合并两边的身份。

ISO 25964 的两个部分分别处理叙词表建设及与其他词表的互操作。这是两个相连、但职责不同的领域。

SKOS 提供机器可读的表达模型，用于表示概念、标签、说明、关系、集合和映射。它属于表示与交换这一层，不是比叙词表更高的一种词表结构。

本体与知识图谱涉及进一步的建模能力，应作为相邻主题比较。是否使用它们取决于需要表达的对象、关系和约束，不能简单理解为词表最终都会升级成知识图谱。

## 建设与维护

维护贯穿词表的建设与使用。它不仅涉及增加词条，还包括改名、调整范围、合并或拆分概念、修正关系，以及处理这些变化对既有内容检索的影响。

修改后的词表能否继续找到原有内容，是维护的重要问题。名称变化可以保留旧入口；概念拆分后，原有内容可能需要重新判断归属；映射对象变化后，两边的对应关系也需要复核。

评价词表时，既要检查结构和记录，也要观察实际标引与检索效果。查全率关注相关内容是否被充分找到，查准率关注找到的内容有多少相关。词条数量、层级深度或格式校验通过，都不能独自证明词表好用。

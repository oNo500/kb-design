# 模型知识译名

状态：已采纳，2026-09-05。用户明确要求新增译名等级，允许使用模型训练形成的既有知识中的行业术语与惯用用词。本决定在指定范围内开放原零自定要求的例外；[译名依据扩展](industry-translation-basis.md)与[译名检索来源](translation-reference-resources.md)其余规则继续有效，旧记录不改写。

## 背景

现有离线中文资料不能为所有课程领域或知识单元提供完整译名及多来源证据。用户要求本阶段速度优先，只使用当前已有离线资料，并明确允许补充模型既有的行业知识。

模型不能逐条追溯训练样本，也不能凭自身输出证明某个用词已被多个独立来源采用。允许使用这种知识，须同时改变准入边界与记录方式，不能仍把它称为已核外部译名。

## 决定

在译名阶梯中加入第 5 级：给定可用资料范围内，前四级未形成可采用结果时，允许 AI 根据训练形成的既有专业与语言知识提出并选择其判断为行业使用的表达。原“不译”移至第 6 级。一般 designation 的五级来源阶梯不增加一个虚构外部来源。

适用范围为已有原名和可读定义或范围的既有概念，包括课程领域和知识单元的语言表示。AI 不据此新增概念、类别或划分特征，不重写定义、上下位关系、映射或稳定 id。

第 5 级不要求两份独立外部用例，也不要求补查在线资料。本阶段固定使用当前已有离线资料与模型知识；未查的在线来源如实记为未查，不冒称已穷尽前四级。已有合格前级译名不被模型输出覆盖，已知的实质含义冲突不能用模型判断强行消除。

记录必须区分模型判断与外部证据，保留原名、所选译名、目标概念范围、判断说明、实际可得的模型标识、生成日期和已查离线资料，并注明“模型既有知识，外部用法未核实”。不得编造训练来源、链接、引文或用例；多次模型输出一致也不构成多个独立来源。

译名的采纳按现行权限或用户明确授权的批次执行；本决定不自动采纳此前待补标签。模型不能给出对应明确的行业用法时，继续保留原名及解释，不为覆盖率拼译。

## 后果

- 零自定要求对上述译名范围开放例外，其他概念命名与划分特征的边界不变。
- 模型知识建议可以补充离线查证结果，但不能进入外部来源命中率；名称建议、依据性质与实际采纳分别报告。
- 后续取得更高等级依据或发现模型误判时可复核名称；概念未变则稳定 id 不变，不因重新生成而自动换名。
- 本次只改设计规则。正式 YAML 的模型判断表示、生成器输入及校验尚未接入，不把模型标识伪装成来源实体，不用现有 `source`、Wikidata Q 号或旧 `self` 混装。
- 不创建或激活来源 v2、正式术语数据、消费者或后置草案。

## 决定依据

本决定依据本次会话中的用户授权：新增一个可使用模型已有训练知识中行业术语和行业惯用用词的等级。它是本库政策选择，不宣称由外部标准规定或背书。本轮依照离线约束未联网。

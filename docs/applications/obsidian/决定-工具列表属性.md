## 使用范围

本决定仅适用于 `/Users/xiu/Documents/knowledge-base` 中《常用工具》的收录与展示。每行对应一篇工具笔记，优先复用描述同一工具的既有笔记；没有适用笔记时，在 `30-resources/` 平铺建立简短参考笔记。文章继续保留独立身份、共同字段和原有状态，不因列入工具列表成为词表实体。

原生 `tags` 中的 `常用工具` 表示个人收录范围。它不替代 `subject`、`entities`、文档类型或正式分类，也不表示本机安装状态。

## 属性含义

三个属性描述笔记所记录的软件资料，仅供本列表使用，不加入[内容模型](../../model/content/设计-内容模型.md)的共同字段合同。

| 属性 | 原生类型 | 内容与约束 |
| --- | --- | --- |
| `tool_purpose` | Text | 一句实际用途；不作为文章摘要或主题分类 |
| `tool_platforms` | List | 已核对的操作系统名称；未核实时省略，不由运行时推断 |
| `tool_install_url` | Text | 一个官方安装说明的 HTTPS 地址；安装命令另放正文 |

可选单值属性省略，可选多值属性省略或保存空列表，不以“未知”等文字代替缺失值。用途、平台和安装入口在属性中维护；正文保留安装命令、版本条件、具体限制、来源及个人使用记录。

同名属性的 Obsidian 原生类型作用于整个 vault；维护时先核对已有类型设置。操作系统支持和安装入口须有可追溯的官方依据，未核内容继续明确保留未核状态。

## 列表规则

`91-views/common-tools.base` 只读取 `30-resources/` 内带有 `常用工具` 标签的 Markdown 文件。筛选条件只确定人工收录范围，不要求三个属性均已填写；缺失属性的记录仍进入列表，相应单元格显示“未填写”。

列表展示名称、用途、平台和安装入口，按名称升序。名称链接到工具笔记，安装入口链接到官方安装说明。`00-indexes/常用工具.md` 保留一句收录说明和 Base 嵌入，不再按用途重复维护多组列表。

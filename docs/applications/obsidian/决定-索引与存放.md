## 目录职责

| 目录 | 职责 |
| --- | --- |
| `00-indexes/` | 人工索引与总入口 |

人工索引提供范围、阅读顺序和关系解释，按需要嵌入 Base；目录按用途存放，不按主题反复细分。领域与资源默认平铺，具体项目需要整体交付、管理或归档时可保留项目目录。总入口位于 `00-indexes/index.md`。

编号表示位置和职责，不决定资料的正式状态。词表、模板和视图处于支撑目录，不因此失去原有语义、依据或维护要求。

## 索引与内容

只承担导航的人工入口放在索引目录；有实质分析、配置事实、项目目标或任务的笔记保留在对应内容目录，通过人工索引链接。标题含“总览”或载体是“索引”，不单独构成移动依据。

人工索引中声明身份的笔记继续使用同一内容字段和稳定 UUID，纳入创建、校验、引用和检索。内容列表按其声明范围读取 PARA 内容，索引导航不等于新增分类事实。

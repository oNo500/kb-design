# 设计与应用分离

状态：已采纳，2026-08-23。决定记录只追加不修改；推翻时新建一条并把本条标为“被替代”。

## 背景

本库只有研究、概念、设计和词表数据；知识库的内容在别处，形态首先是 Obsidian，以后可能是 DITA 或其他。如果设计文档直接写 Obsidian 的 properties、tags，换形态时设计作废。

## 决定

设计分两层。与应用无关层（概念、词表、内容模型、导出与回流的规则）不提任何工具的字段名和文件格式；应用相关层（`design/targets/` 每种应用一篇映射）回答内容模型的五个问题，不改动与应用无关层的定义。`vocab/` 是源，各应用从它导出，不反向编辑。

## 后果

- 内容模型只叫“内容单元”，不叫笔记或 topic
- 每换一种应用只写一篇映射，设计不动
- 回流的计数要读内容，必须经过映射；首个映射落地前计数类指标不触发

# 来源执行

状态：已采纳，2026-09-05。用户明确确认执行来源 v2 正式迁移阶段，随后要求使用 Git 版本管理，不实现额外回滚；取证优先使用本地可直接阅读、无需复杂解析的材料，其他复杂耗时材料标记“不核对”。

## 执行范围

来源 v2 迁移的证据提案、范围确定和必要实现已经开放，不再受[当前阶段](current-stage-scope.md)关于来源候选与正式迁移整体冻结的限制。此授权不开放术语正式切换，不使来源或术语草案整体生效，也不批准具体实体事实、映射关系、用途角色或发版。

优先复用现有 schema、校验器、索引、迁移代码和已留存的阅读记录。先完成可直接处理的资料与字段，再确定实际迁移写集；不为追求完整形式新增通用框架、重复验证或没有接收方的产物。

## 取证顺序

本地 Markdown、纯文本和已保留的可读记录先处理。记录必须说明材料性质、原核对日期、位置与支持范围；历史阅读记录可以进入采纳提案，但不冒充本轮重新读取外部原页。既有字段的结构化读取可以使用现成工具，不为本批新建解析器。

需要下载、PDF 转换、OCR、复杂结构提取、批量数据导入，或本地没有相应原文的材料，本轮标记“不核对”。这表示有意跳过，不表示已核、无问题或可以批准。不自动联网或新增下载。

“不核对”保留到对应字段与记录。它不阻止无依赖事项继续准备，但不能通过删除阻断、填入猜测值、回填今天的 checked 或改写历史账本让记录通过。跳过必需证据的记录不进入正式切换写集；如果当前 schema 或消费者不支持混合状态，不能为赶进度擅自混合发布。

## 版本恢复

取消本次来源迁移的补偿回滚框架与专用回滚实现。此范围替代[来源迁移](source-migration-policy.md) Q25 中对本次执行的 compensation 要求；历史控制 patch 与冻结测试材料保留原样，不改写为新规则。

使用隔离分支和小范围提交保留迁移前后版本。撤销已提交迁移时使用明确提交范围的 `git revert`，不使用 `reset --hard` 或清理命令覆盖未知用户修改。受跟踪文件的恢复范围以 Git 写集为准；正式 vault 与 Git 忽略的应用数据不在本次迁移写集，不宣称 Git 能恢复它们。

保留身份、引用、数据完整性与消费者兼容检查，不为恢复流程再造一套状态机或副本管理系统。复用已有交付能力时只保留本次真实切换需要的部分，不自动沿用旧计划的整套 payload、handoff 和补偿链。

## 决定边界

开启执行与批准具体值分开。AI 先形成字段级旧值、新值、可用依据、未核范围与影响文件，再由人按现行权限采纳。材料不足只阻断相应正式值；已授权的其他取证和实现不以小批次为单位重复请求开始许可。

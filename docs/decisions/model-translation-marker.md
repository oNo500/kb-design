# 模型译名标记

状态：已采纳，2026-09-05。用户要求把 `model` 标记及其配套要求写清楚。本决定落实[模型知识译名](model-knowledge-translation.md)的表示方案，旧决定保留。

## 背景

模型知识译名已经获得规则上的使用资格，但尚无正式数据表示。只显示中文标签会掩盖依据性质；继续写 `source`、Wikidata Q 号或旧 `self` 会与现有语义混淆。

## 决定

语言标签的目标依据使用保留值 `model`，即 `basis.zh: model` 或 `basis.en: model`。它不指向实体表或来源用途表，也不适用于概念派生、映射或其他字段断言。

详细判断沿用译名决定输入中的稳定概念 id 与语言键，保存所选标签、是否采纳、模型标识、生成日期、原名与范围、判断说明、实际离线资料和采纳记录。外部用法未核实是固定语义；完整字段、生成兼容、校验与显示要求见[主题词表的模型标记](../topics.md#模型标记)。

人读页面在名称旁直接显示模型知识及第 5 级，明确外部用法未核实；机器表示保留标记，不能把它当作外部来源 ID。任何模型输出不得自动改变概念身份、关系或生命周期。

## 后果

- 生成输入、输出、校验及使用方须共同识别该标记；缺少配套采纳记录不能只凭字符串通过验收。
- 旧 Wikidata 输入及旧 `self` 语义保留；不把旧的自译记录自动转为已采纳模型译名。
- 本次只确定合同，不修改正式 YAML、现有采纳输入或生成实现；具体标签仍按已授权采纳结果落入生成链。
- 模型标记的实施不激活正式术语数据、来源 v2、消费者或其他后置草案。

## 后续决定

2026-09-05，[语言依据结构](structured-label-basis.md)替代本决定中的字符串 `model` 表示及沿用 `label-decisions.json` 的输入位置。现行结构、独立采纳记录和已授权补全批次见新决定；原文保留为当时合同，不再作为未实现状态的当前说明。模型不是外部来源、保留历史与生命周期边界的要求继续有效。原“模型标记”小节由[语言依据](../topics.md#语言依据)承接。

# 预览归属

状态：已采纳，2026-09-05。用户批准将现有本地词表预览纳入 monorepo 维护，并在保存仓库内词表后自动更新页面。

## 应用位置

预览源码位于 `apps/vocab-preview/`，作为 uv workspace 成员维护。运行入口为 `uv run kb-vocab-preview`，默认使用应用所在仓库的 `data/vocab/`，支持显式数据根与端口，仅监听本机。

## 编辑边界

预览读取工作区文件，包括未提交的修改，页面只读。它不修改数据、批准标签或关系，不启用来源 v2、正式术语数据或正式内容消费者，也不改变 [Obsidian 快照](obsidian-tool-location.md)与[仓库布局](monorepo-layout.md)的其他边界。

## 维护范围

复用现有页面与采集逻辑，维护条目、层级、关系、来源依据及原始 YAML 表示。本次采用自动重载，精细浏览状态保留后置；不引入编辑功能、云服务或发布流程。

原本地预览目录保留备份，不再作为运行依赖。实时表示在内存中生成，旧静态快照和研究材料不复制到应用源码。数据或表示规则变化时，应同步[应用设计](../design/targets/vocab-preview.md)、实现和相应行为检查。

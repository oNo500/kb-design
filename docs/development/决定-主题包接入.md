# 主题包接入

状态：已采纳，2026-09-24。用户批准将 quietpaper 作为独立子包纳入当前项目，保留 Bun 工程，部署使用显式目标，验证仅使用临时目录。

## 包的职责

`packages/quietpaper/` 维护 Obsidian 主题源码、配色、构建、样本和显式部署入口。主题负责显示，不解释或修改知识模型、字段、词表身份与文章状态；不作为新的内容消费者或 Application Profile。

本次按固定上游提交直接导入源码，由当前仓库维护，不使用 Git submodule，也不合并上游 Git 历史。包内保存仓库地址、提交及文件摘要，保留作者信息；未提供的许可证不自行补定。

## 工程边界

Python 工程继续使用根 uv workspace 与统一 `uv.lock`。主题包独立使用 Bun、`package.json` 与 `bun.lock`，不加入 Python 依赖，也不建立根级 JavaScript workspace。原有 CSS 与配色保留，构建路径按包目录解析。

主题源码、配色生成文件、主题产物及样本一同维护。第三方依赖留在被忽略的 `node_modules/`；临时导入材料和检查输出放在根 `build/`。

## 部署边界

`sync` 和 `deploy` 必须显式提供目标知识库。目标应已存在且包含 `.obsidian/`，不得保留上游硬编码的 iCloud 目标；主题部署只写两个主题文件，不自动选择主题、重载应用、迁移内容或更改词表交付。

本次只在临时目录验证构建和部署，不安装或启用正式知识库主题。实际库的配置维护继续依其既有授权和写集执行。

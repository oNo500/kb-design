原整体设计及多语言决定中关于文档分工的条款按本决定调整；原来源范围、名称身份、译文复核、映射用途及具体采纳继续有效。旧第 3 版及 YAML 合同继续约束当前数据，目标规范不能被当成已经切换的输入合同。

历史决定和已采纳提案保留原文，必要时追加位置说明。旧路径及锚点按[迁移记录](../../work/reviews/2026-09-19-vocabulary-design-practice.json)解释，历史审计不回写。记录问题、研究或修改设计不自动启用新语种、模型、消费者、索引、查询日志或发版。

本次只处理文档。生成器、校验器、schema、来源、词表数据、外部知识库及运行服务均不在改动范围；标准未核内容不因文档整理而成为已核。

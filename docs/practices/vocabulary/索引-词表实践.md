# 词表实践

本目录保存现行词表的数据合同、实现与操作说明，用于维护现有项目和规划迁移。目标要求由[词表整体设计](../../model/vocabulary/设计-词表整体设计.md)及其专题规范规定；实践能力或限制不能直接修改目标。

## 数据合同

| 文档 | 适用对象 |
|---|---|
| [现行数据规范](设计-现行数据规范.md) | 第 3 版 RDF／SKOS 普通标签输入、字段、来源兼容及旧语言接口 |
| [实体记录现行合同](设计-实体记录现行合同.md) | 实体 YAML 字段、来源依据、类别、状态与校验；目标分工另见实体设计 |
| [主题词表](设计-主题词表.md) | 现行 YAML 主题数据、生成输入及语言依据 |
| [层级结构](设计-层级结构.md) | 现行 YAML 学科层级、数组、具体来源与范围 |

现行合同在其适用范围内继续有效。目标规范、文档移动或名称变化本身不切换数据格式、编辑源、消费者或发布状态。

## 实现与操作

- [词表工程能力](设计-词表工程能力.md)：来源处理、生成、校验、维护和中文批译的实现记录、接口及已知差距。
- [词表工具链](指南-词表工具链.md)：来源准备、同步、编辑、重试、查询、应用加载和版本恢复的操作入口。
- [词表校验规则](../../../packages/kb-vocab-shacl/README.md)：依据目标设计维护的独立 SHACL 包；覆盖边界见[规则覆盖](../../../packages/kb-vocab-shacl/COVERAGE.md)，尚未接入现行工具链。
- [CCS 词表适配](../../../packages/kb-vocab-ccs/README.md)：固定 GitHub 原件，经程序补充 XL 名称及已采纳元数据，复用结构统计与校验；独立生成，尚未接入旧发布流程。

- [词表分类树](../../../apps/vocab-rdf-preview/README.md)：只读展开 Turtle 词表的分类层级。

- [写作词表处理](../../../packages/kb-vocab-writing/README.md)：复用来源采集，维护带出处的写作概念输入，生成 Turtle 样稿及字段统计；确认与机械检查分别记录。

能力记录注明核对时间和证据；运行命令需满足相应范围与权限，文档不代替一次具体执行的结果。

实践问题记录条件、相关版本与设计要求、预期与实际结果、证据及影响，区分事实、原因假设和待核问题。记录保留在既有审查或研究位置，不自动构成设计缺陷或设计变更许可。

是否研究、采用哪种标准或成熟方案、是否形成新设计按治理权限决定；已采纳的新设计再用于实施。不得以现有代码、兼容成本或一次校验通过倒推设计要求。

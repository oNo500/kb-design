# 概念文索引

`concepts/` 解释本库用到的理论:它是什么、解决什么问题、为什么成立。规则在 `design/`,文献笔记在 `sources/`,术语查 [术语表](glossary.md)。

## 文章的关系

```
知识组织
├─ 受控词表                  一份词表是什么、有哪几种
│   ├─ 词表的层级            一个概念下面怎么分
│   ├─ 分面                  整个词表先切成几棵树
│   ├─ 概念组                按用途圈出的视图
│   └─ 词表的建设与维护      一份词表怎么建、怎么改
├─ 词表映射                  多份词表之间怎么对应
├─ 知识体系                  不是词表,但可作词表上层结构的来源
└─ 知识图谱                  词表的升级方向

方法论
└─ 第一原理与设计理由        本库采用任何方法前的检验
```

## 词表结构总览

结构三篇加映射一篇合起来是这张图。左边是词表内部,右边是外部词表;例子用「人」,方括号标出术语归哪篇:

```
词表的全部概念                                          外部词表
│                                                       ┌──────────────┐
├─ 第一次归类:分面 [分面]   人物 | 动作 | 地点 | 时间    │ ASVS         │
│                                                       │ CWE          │
│   每个分面各自成一棵树 [层级]:                         │ OWASP Top 10 │
│                                                       └──────┬───────┘
│   人物                          ← 顶层概念                   │
│   └─ 人                         ← 概念,树上的节点            │
│       (按年龄)                  ← 节点标签:划分特征  ◀─ 借入 ─┤ 结构抄进来,成为数组 [映射]
│       ├─ 儿童  ┐                                             │
│       ├─ 青年  ├─ 数组                                       │
│       └─ 成人  ┘                                             │
│       (按职业)                  ← 第二个划分特征             │
│       ├─ 医生  ┐ 数组                                        │
│       └─ 教师  ┘                                             │
│                                                              │
│       张三:成人、医生           ← 多层级  ── 映射 ──────────▶│ 指向外部条目 [映射]
│                                                              │
└─ 按用途圈一批:概念组 [概念组]                                │
    「急诊科常用词」= {医生, 手术, 病房, 术前}   手工圈定       │
    「OWASP Top 10」= 映射到它的全部概念   ◀─ 由映射派生 ───────┘
```

## 词表结构总览

两张图。第一张是词表内部，例子用“人”，方括号标出术语归哪篇：

```
词表的全部概念
│
├─ 第一次归类:分面 [分面]            人物 | 动作 | 地点 | 时间
│
│   每个分面各自成一棵树 [层级]:
│
│   人物                              ← 顶层概念
│   └─ 人                             ← 概念,树上的节点
│       (按年龄)                      ← 节点标签:划分特征
│       ├─ 儿童  ┐
│       ├─ 青年  ├─ 数组
│       └─ 成人  ┘
│       (按职业)                      ← 同一概念下的第二个划分特征
│       ├─ 医生  ┐ 数组
│       └─ 教师  ┘
│
│       张三:成人、医生               ← 多层级,一个概念多个上位
│
└─ 按用途圈一批:概念组 [概念组]      「急诊科常用词」= {医生, 手术, 病房, 术前}
```

第二张是本地词表与外部词表的关系 [映射]。ASVS、CWE、OWASP Top 10 是三个互不相干的外部体系，各演示一种用法；用一个本地概念把三种串起来：

```
本地概念 sql-injection
  ├─ 挂在数组「(按验证要求)」下的 input-validation    ← 数组的结构借自 ASVS
  ├─ match → CWE-89                                   ← 映射到 CWE 的一条
  └─ match → A03:2021                                 ← 映射到 OWASP Top 10 的一条
                                                         由此自动属于派生组「Top 10」
```

| 用法 | 外部体系 | 做了什么 | 在本地变成什么 |
|---|---|---|---|
| 借入 | ASVS | 把它的章节结构抄进来 | `security` 下的一个数组，成员是本地概念 |
| 映射 | CWE | 本地概念指向它的一条 | 概念记录里的一条 `match` |
| 派生 | OWASP Top 10 | 把映射到它的本地概念圈成一组 | 一个概念组 |

一个概念挂在谁的结构下，和它映射到谁，是两回事：前者由本地的树决定，后者看外部哪里有对应条目。

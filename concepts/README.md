# 概念文索引

`concepts/` 中的文章解释本库使用的理论：它是什么、解决什么问题、为什么成立。规则见 `design/`，文献笔记见 `sources/`，已登记的名称见[术语表](glossary.md)。

## 文章的关系

```
知识组织
├─ 受控词表                  概念怎样由已核实的名称、标目或代码表示并组织
│   ├─ 词表的层级            概念之间的上下位关系怎样组织
│   ├─ 分面                  概念怎样先按内在类别归类
│   ├─ 概念组                怎样按用途圈出概念视图
│   ├─ 词表的建设与维护      怎样从输入判断概念并维护概念记录
│   └─ 新主题的分类          标准里没有的主题怎样分类
├─ 词表映射                  多份词表中的概念怎样对应
├─ 知识体系                  各类体系怎样提供结构、核对或映射材料
├─ 元数据                    字段从哪里来，受控词表怎样为字段提供值
├─ 笔记的类型                体裁、作者立场、成熟度、载体和认知层级怎样分开描述
└─ 知识图谱                  词表怎样扩展为带类型的实体关系

方法论
├─ 第一原理与设计理由        怎样检验方法的起点并保存决定理由
├─ 写作规范                  写作规则怎样从面向读者的原则推出
└─ 治理                      怎样管理决策权、政策、变更和审计
```

## 词表结构总览

第一组示例说明一份词表内部的结构。例子使用“人”，方括号标出解释相应结构的文章。

```
词表中的全部概念
│
├─ 按内在类别归类：分面 [分面]        人物｜动作｜地点｜时间
│
│   每个分面各自形成层级 [词表的层级]：
│
│   人物                              ← 顶层概念
│   └─ 人                             ← 概念，树上的节点
│       （按年龄）                    ← 节点标签，说明划分特征
│       ├─ 儿童  ┐
│       ├─ 青年  ├─ 数组
│       └─ 成人  ┘
│       （按职业）                    ← 同一概念下的另一个划分特征
│       ├─ 医生  ┐ 数组
│       └─ 教师  ┘
│
│       成年医生：成人、医生          ← 多层级，一个概念有多个上位概念
│
└─ 按用途圈出概念组 [概念组]          例如，按急诊工作所需圈出 {医生，手术，病房，术前}
```

第二组示例说明本地词表与外部体系的关系。ASVS、CWE 和 OWASP Top 10 分别演示复制、映射和派生，一个本地概念把三种用法联系起来。

```
本地概念 sql-injection
  ├─ 位于数组“（按验证要求）”中的 input-validation 之下  ← 数组结构来自 ASVS
  ├─ match → CWE-89                                      ← 映射到 CWE 的一条
  └─ match → A03:2021                                    ← 映射到 OWASP Top 10 的一条
                                                            由此进入派生概念组“Top 10”
```

三种用法在本地承担不同职责。

| 用法 | 外部体系 | 做法 | 本地产物 |
|---|---|---|---|
| 复制 | ASVS | 把它的章节结构转成本地结构 | `security` 下的一个数组，成员是本地概念 |
| 映射 | CWE | 让本地概念指向它的稳定条目 | 概念记录中的一条 `match` |
| 派生 | OWASP Top 10 | 圈出所有映射到它的本地概念 | 一个概念组 |

概念位于哪一套本地结构中，与它映射到哪个外部条目，是两件事。前者由本地的层级决定，后者由概念之间的对应关系决定。

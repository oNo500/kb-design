# 概念文索引

`concepts/` 解释本库用到的理论:它是什么、解决什么问题、为什么成立。规则在 `design/`,文献笔记在 `sources/`,术语查 [术语表](glossary.md)。

## 文章的关系

```
知识组织
├─ 受控词表                  一份词表是什么、有哪几种
│   ├─ 词表的层级            一个概念下面怎么分
│   ├─ 分面                  整个词表先切成几棵树
│   ├─ 概念组                按用途圈出的视图
│   └─ 词表的建设与维护      一份词表怎么建、怎么改
├─ 词表映射                  多份词表之间怎么对应
├─ 知识体系                  不是词表,但可作词表上层结构的来源
└─ 知识图谱                  词表的升级方向

方法论
└─ 第一原理与设计理由        本库采用任何方法前的检验
```

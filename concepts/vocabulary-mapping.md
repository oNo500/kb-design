# 词表映射 (Vocabulary Mapping)

## 定义

词表映射是**在一个词表的概念和另一个词表的概念之间建立对应关系**。ISO 25964-2 §3 的定义:映射是映射过程的产物,即一个词表中的概念与另一个词表中一个或多个概念之间的关系。映射通常有方向:从源词表指向目标词表。

一组映射的集合叫 **crosswalk**(对照表):两个以上结构化词表之间概念映射的表。

映射解决的是**互操作**:两个系统各用各的词表,要让在一边标引的内容能在另一边被检索到,或者让本地词表能借用外部词表的权威条目。

## 解决的问题

| 问题 | 例子 | 映射的处理 |
|---|---|---|
| 本地概念没有权威依据 | 自己定义的 `sql-injection` 谁认? | 映射到 CWE-89,权威性借过来 |
| 多个外部体系对同一概念各有条目 | CWE、OWASP Top 10、ATT&CK 都有注入 | 一个本地概念,多条映射,各标关系类型 |
| 外部体系改版,本地不知道哪些受影响 | CWE 4.20 合并了两个条目 | 映射记录了外部 id,可以按 id 查变更 |
| 两个系统要合并或联合检索 | 两个知识库要打通 | 建 crosswalk,检索时翻译 |

## 映射的类型

ISO 25964-2 §8–11 分三类,与叙词表内部的三种关系平行:

| 类型 | 含义 | SKOS 属性 |
|---|---|---|
| **等价映射** | 目标词表中的概念与源概念范围相同 | `exactMatch` / `closeMatch` |
| 　简单等价 | 一对一 | 同上 |
| 　复合等价 | 一个概念对应另一边两个以上概念的组合 | SKOS 无直接表达 |
| **层级映射** | 目标概念比源概念宽或窄 | `broadMatch` / `narrowMatch` |
| **相关映射** | 有关但非等价非层级 | `relatedMatch` |

等价再按程度分(§11):

| 程度 | 含义 | SKOS |
|---|---|---|
| 精确等价 | 范围完全一致,任何检索场景可互换 | `exactMatch` |
| 不精确等价 | 范围大致一致,多数场景可互换 | `closeMatch` |
| 部分等价 | 一边的范围只覆盖另一边的一部分 | 用 `broadMatch` / `narrowMatch` |

SKOS 的两条重要语义:`exactMatch` 是传递的(A=B, B=C ⇒ A=C),可以跨多个词表串链;`closeMatch` **故意不传递**,防止「大致相等」一层层累积成错误。所以拿不准时用 `closeMatch`,它不会传染。

ISO 25964-2 把「区分映射类型和等价程度」的做法叫 **differentiated mapping**(区分式映射),相对于只记「有对应」的 undifferentiated mapping。

## 映射的结构模型

ISO 25964-2 §6 给了三种模型:

| 模型 | 做法 | 适用 |
|---|---|---|
| 结构统一 | 几个词表共用一套结构,各自只是不同语言或视图 | 多语种叙词表 |
| 直接链接 | 每对词表之间单独建映射 | 词表少 |
| 中心辐射 | 所有词表映射到一个中心词表,彼此通过中心转换 | 词表多;n 个词表只需 n 套映射而不是 n² |

本库的做法是中心辐射的简化版:本地 `topics` 是中心,所有外部体系映射到它,外部体系之间不互相映射。

## 与各类词表互操作

ISO 25964-2 §17–24 逐类讲了叙词表与其他词表互操作时的差异,对本库相关的:

| 外部词表类型 | 差异 | 映射时注意 |
|---|---|---|
| 分类法(§17)、taxonomy(§19) | 先组、只有层级、无同义控制 | 一个类目常对应多个概念的组合 |
| 本体(§21) | 关系类型任意、有形式语义 | 叙词表的 BT/NT 与本体的 subClassOf 不完全等价(BT 可以是整部、实例) |
| 术语库(§22) | 以词为中心,概念定义严格 | 术语库的「概念」粒度通常比叙词表细 |
| 名称规范表(§23) | 收的是个体(人、机构)不是类 | 不与主题概念做等价映射 |

## 在知识库中的用法

1. 每个本地概念可有多条映射,各标类型;映射目标的 id 和所属体系分开记,体系的版本在来源登记里统一维护
2. 默认用 `closeMatch`;只有范围确认完全一致才用 `exactMatch`——后者会传递
3. 映射的目标必须是**有稳定条目**的体系(有编号或永久 URL)。学习路线、排行榜没有稳定条目,只作候选词来源,不作映射目标
4. 外部体系改版时,按 id 查变更日志,只复核受影响的映射
5. 映射是概念级的,不是分支级的。「security 对标 ASVS」是说明,不是映射

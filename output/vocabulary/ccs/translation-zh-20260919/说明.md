# CCS 中文初译

本次为用户批准的一次性首选名称翻译，不是长期翻译工具，也不改变原件、英文词表、概念身份和分类关系。

## 翻译结果

2,299 个概念全部有处理记录：2,146 个补充中文，153 个保留原名。保留项中 138 个位于人物、技术与公司分支，其余 15 个为专用名称、课程代号或语义有歧义的条目。保留不等于漏项；每条都有原因，未将原英文改标为中文。

中文均为模型知识初译，第 5 级，外部用法未核实，未经人工复核。五组中文同名已列入 summary.json，仍保留不同概念身份，不据同名合并。别名、隐藏名和说明没有翻译。

本次 `structure` 与 `target` 均通过，0 条问题，合计 439.74 秒。报告核对的是当前中文词表哈希；不等于译文经过人工审核。

## 文件职责

| 文件 | 内容 |
| --- | --- |
| `tasks.json` | 脚本提取的概念编号、英文名称、语言和分类语境 |
| `source.json` | 固定英文词表路径与 SHA-256 |
| `batches/` | 九批输入及模型原始翻译结果 |
| `result/vocabulary.multilingual.ttl` | 中英文词表，保留全部原图陈述 |
| `result/translations.json` | 逐项任务、译文或保留结论、源版本、批次、状态及 Label IRI |
| `result/batches.json` | 执行代理、模型信息、结果写入时间、依据及批次授权 |
| `result/name-registry.json` | 本次中文名称的身份登记，按首次任务固定分配 |
| `result/summary.json` | 数量、疑难项及中文同名提示 |
| `result/manifest.json` | 产物哈希、生成脚本哈希及词表基准 |
| `result/preview.html` | 带“模型初译、未人工复核”提示的只读分类树 |
| `validation/` | 实际运行的结构与目标规则、完整报告及摘要 |

模型精确版本没有由本次工具返回，记录中留空并注明原因；不从配置推断实际版本。翻译执行者按实际 Codex 子代理记录。结果文件写入时间明确标为 UTC，不冒充人工复核时间。

## 浏览入口

在仓库根目录运行：

```sh
uv run python -m http.server 8767 --bind 127.0.0.1 --directory output/vocabulary/ccs/translation-zh-20260919/result
```

打开 <http://127.0.0.1:8767/preview.html>。此页是本次结果快照，明确显示初译提示；原英文预览和默认构建没有替换。

## 生成记录

`extract.py`、`merge.py` 和 `check.py` 是本次一次性脚本。合并脚本从固定英文词表和批次输入生成全新目录，核对原图完整保留及关系不变，按任务分配并登记中文 Label，再回读核对 RDF 图。不得直接修改生成的 `.ttl`。

校验使用现有 `kb-vocab-shacl`，对原英文生成名称与新中文登记名称的并集明确启用 LocalLabel。其他本地条件未指定对象，不宣称已执行。SHACL 通过也不等于中文语义经过人工确认。

本目录位于持久 `output/`，不属于可清理的 `build/`。该路径默认被 Git 忽略，本次按用户“全部提交”的明确要求纳入 Git。没有更改现有包、目标设计或正式发布流程。

## 格式适配

原件已有 SKOS 数据，无需从普通 XML 重新建模。转换仅处理：

- 内部 DTD：核对四个固定命名空间声明后展开，拒绝其他声明，不加载外部实体。
- 词表 URI：把原 URI 中的空格替换为 `%20`，全部引用同步转换；原值与新值记录在 `conversion-report.json`。
- 相对编号：原件使用 `#10002944` 等片段且没有 `xml:base`。以固定提交的下载 URL 解析，避免使用本地磁盘路径。解析后 IRI 是该快照的标识，不宣称是 ACM 官方永久概念 IRI；更换快照时须按原编号处理身份延续，不能直接把新 URL 当成新概念。

## 核对范围

逐条 XML 字段构建的预期图与转换图相等；Turtle 重新读取后与转换图同构。18,755 条 RDF 陈述全部保留，原件哈希未变。层级与相关关系无悬空端点，上下位关系互为反向，无层级循环，全部概念可从顶层到达。

这些结果证明本次转换保留数据及上述结构性质，不证明逐条语义正确、内容最新或符合项目全部目标设计。字段统计未运行 SHACL 校验引擎。

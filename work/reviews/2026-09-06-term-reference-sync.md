# 术语引用同步

## 执行范围

按已采纳完整术语提案的 `conditional_execution_proposal` 第二阶段，同步当前概念说明中明确指向同一概念的名称与定义。范围仅为现有 `docs/concepts/` 文章及本记录；不修改术语数据、决定、schema、历史归档、字段名或编辑源状态，不访问正式 vault。本轮不重新联网取证。

## 语义风险

需要防止三个实际失败：定义换源后仍保留互相冲突的前提；旧 designation 在概念正文中仍被当作准用同义形式；名称纠正意外改变应用能力声明或内容必填条件。证据来自已采纳包的前后定义、逐条取证记录以及这些正文的明确用法，不以字符串计数代替概念对应判断。

## 同步内容

- `reproducible-builds.md`：全文按 IEEE 固定作者稿 Definition 1 重写。完整保留具体源码版本、全部构建依赖、每次逐比特相同、无论执行环境四项条件；官网相同环境及指令条件单列为对照与实践入口。旧双跑、独立重建、manifest、provenance、JCS、BagIt 与原子替换的证据边界分别保留。另明确一次独立重建也不足以单独证明所有环境的全部构建一致，当前应用仍仅声明同环境确定性等既有局部能力。
- `note-types.md`：认知过程维度取代指向修订版分类的旧认知层级，说明六类认知活动与知识维度交叉分类教育目标。原 SOLO 五项移入相邻分类说明，不混成同一维度的另一组刻度。例子改为复述定义与应用方法；`level` 仍可选且用于自评。原类型、立场、载体及内容状态的约束统一指向现行内容模型，未新增必填项。
- `README.md`：两处指向笔记类型文章的描述同步为认知过程维度；术语表作为 glossary 的读者入口保持。
- `governance.md`：治理采用 ISO 37000 完整目的与问责定义；治理主体的正式意向和方向明确为治理政策／governance policy。旧“对管理的管理”降为解释用语。ISO 15489 原章名保留，撤去仅凭政策章名将整章等同治理层的推断。项目规则约束、决策权限与既有义务保持，普通政策叙述不批量改名。定义来源改为已核 ISO 样章，旧 DAMA 转述不再承担本节定义。
- `facet.md`、`metadata.md`：仅把 `type` 允许值所对应的平铺受控词表结构改为列表。`facet.md` 中“术语表的辅助表条目”和其他正文中的术语表仍指 glossary 或来源中的参考材料，予以保留。
- `knowledge-graph.md`：原平铺结构“代码表”统一到列表。同时同步已经明确绑定的 schema、本体、relation、edge、property 与 reasoning：对象和图表示分开，schema 不再等同本体，属性不再等同字面值，推理不以新增边为必要条件。旧单向升级谱改为词表与图谱的关系说明，保留命名、层级和相关关系三个原主题，但不再暗示自动转换。技术路线与应用段未新增功能或类型许可。

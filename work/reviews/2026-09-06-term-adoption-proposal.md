## 结构范围

概念、语言、术语三层结构及 `tc-`、`tm-` UUIDv4 身份格式继续使用。概念和形式分配不同身份；不能把每行表格机械转换为概念。语言使用实际有依据的 `zh-Hans`、`zh-Hant` 或 `en`，纯英文不复制为中文，缺失项不补造。

`subject_fields` 在领域未定时可以为空；章节布局按概念 ID 列成员，章节 ID 不当作主题 ID。首选、允许形式及状态由具体值采纳决定，不能按斜杠、逗号或列顺序判定。关系指示符、属性代码和来源枚举不自动成为术语概念。

外部依据保留严格 entity、locator 及适用 checked。第 5 级只允许为既有且含义明确的概念提出中文模型语言依据，保存实际模型、日期、理由与精确采纳引用；它不替代概念、定义、领域和外部关系依据，不覆盖合格前级依据。

旧登记保留既有效力，旧账本的 6 条待 L3 项不删除、不自动转成模型译名。冻结输入和 Git 保存历史，不补造历史准入日期或把未核材料写为本轮已核。

## 具体数据

当前[术语数据提案](2026-09-06-term-data-candidate.md)及[完整字段](2026-09-06-term-data-candidate.json)逐行保存去向：56 个定义行形成 65 个概念建议，84 行保持现行登记待证据，3 行保留为项目字段或 SKOS 属性说明。所有具体值均未采纳，提案身份与拟议 active、首选、准用值不是正式状态。

混合行按组件分别核对：建设方向、演绎与归纳、查全率与查准率、源与目标词表、等价程度、四项 plain language 原则、三类笔记、隐性与显性知识。准确形式、独立定义、对应依据分别记录；原[组件字段提案](2026-09-06-term-field-proposals.json)中的 20 个组件及当时 6 个定义缺口保留为审查历史，现值以完整字段包为准。属性代码和技术对象是否独立治理仍按实际用途判断。

词表层 crosswalk 保留待核，不以 DCMI metadata crosswalk 替换；mapping 不因样章存在过程义就新增概念。实体与属性的定义修正、单层级与多层级的英文改名，以及其他冲突与残余形式都在字段包明确列出，须人决定，不能凭标点或模型印象确认同义。

## 证据与来源

必要只读取证已获范围授权；已有阅读记录、标准原文、公开说明、论坛转述和模型判断分别登记，不因缺少本轮副本否认此前有效阅读，也不将旧登记自身充当新增外部事实依据。NISO、IPLF、ISO、Ahrens 及冻结登记中其他必要来源的结果见具体字段包所链证据；取不到的材料保留限制，不补造 checked。

[来源候选](2026-09-06-term-source-candidate.md)及其[完整字段](2026-09-06-term-source-candidate.json)覆盖当前 13 项新来源依赖。它们仍是候选，不改变现有来源或用途角色；来源实体的采纳和术语具体引用的采纳分别满足条件。只读联网许可不等于具体值批准，不新增持久下载、OCR 或资料平台。

## 编辑权边界

模型译名继续属于主题、载体词表与 `label-adoptions.json`。生成区只按相同中英形式合并展示并保留全部对象身份；不同含义不合并，不建立 `tc-*`、`tm-*` 或委托。原 `original.scope`、历史路径及第 5 级“外部用法未核实”声明保留。

具体包建议另设 `data/inputs/terminology/retained-glossary.md`，原样保留 84 条待核定义、3 条说明、6 条缩写和 14 条文献说明，共 107 行，并承接已迁移行中的残余形式。这个保留编辑源及相应效力和布局仍待人采纳，不能从迁移审计长期读取生产值，也不能丢掉旧项来获得通过。

拟议完整 glossary 分别读取获准术语数据、保留登记、模型标签及章节布局，每个对象只有一个编辑源。精确 state 建议值与各类编辑源读取合同已纳入具体包；保留源读取、完整生成及实际切换仍待采纳后实施。当前 `docs/glossary.md` 继续是现行编辑源，没有正式 terms/state。

## 应用合同

可选 terms/state 必须共同存在，且经核心完整验权，才能从同一干净 Git 快照导出 `kb/terms/<tc-id>.md`。术语概念身份、形式身份与主题身份分开；页内保存形式、定义、范围、出处与依据性质，不自动产生主题分类。

输入捕获、术语渲染、manifest 身份与路径、参考目录及刷新链接检查已接入。模型标签无独立术语概念时不生成术语页。刷新写集仍为 `kb/` 和 `app/manifest.json`；工程接入不表示正式消费者启用，本次没有正式 vault 写入。

## 工程进展

统一 `term_validation` 已供生成、维护与应用调用，检查 schema、来源引用、精确采纳、稳定身份、状态历史和发布授权。新候选首次准入与旧首选词替换分开；身份删除、跨概念或跨语言搬移、无授权形式及定义变更不能凭决定 ID 存在而通过。

`build-terms` 在写出前严格校验，章节布局与领域分离，输出保留定义、形式和依据。`term-data check/index` 使用同一入口校验与定位实际引用；`check-terms` 已支持正式切换后读取获准形式，未切换时保留现行登记诊断。可选 Obsidian 术语读取已实现。

早期修复证据见[术语准备进展](2026-09-06-term-preparation.md)；该历史记录只覆盖当时限定修复。后续实现不将其旧测试结果扩大为完整验收。具体数据、保留编辑源与生成衔接、正式迁移和统一验收仍未完成，不能宣称可接入，也未合并 master。

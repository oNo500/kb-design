## 读取边界

决定的中文名称通过 documentation.py 中的明确映射保留原 source／term 选择名。映射不改变 ID、schema、采纳字段或有效状态；未知中文决定名不自动获得来源或术语读取分组。重复 ID 的拒绝规则及提案排除保持。

应用以 Git 的 NUL 分隔输出读取决定文件，避免 core.quotepath=true 将中文名转义后误判文件集不同。该问题在修复前以真实临时提交复现，修复后同一读取和导出用例通过。

术语表的新路径是 docs/参考-术语表.md。当前编辑源仍是 data/vocab/terms.yaml；已采纳布局和历史回滚字段不改写。本次没有启用新的回滚行为。生成器仅调整本地阅读链接，程序与使用文档指向新的参考页。

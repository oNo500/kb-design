# 文档命名验收

## 实施范围

用户于 2026-09-12 批准概念文使用“概念-名称.md”、设计正文使用“设计-名称.md”，名称取现有中文标题。共重命名 18 篇概念文和 17 篇设计正文，归属与文件去向见[命名迁移清单](../plans/2026-09-12-docs-chinese-files.json)。

Application Profile 和 Reproducible Builds 沿用已登记的英文名称；主题首页、概述、阅读笔记、决定、提案、操作指南和生成术语表沿用原文件名。当前规则见[文件命名](../../docs/governance/writing/设计-写作规则.md#文件命名)。

## 引用处理

现行导航及链接指向新文件。空格在 Markdown 链接中编码为 %20，中文直接书写；相对链接检查器按 URL 编码解码后核对文件。历史决定与既有执行记录不改写，检查器按两次明确迁移的连续关系解析历史路径。

## 验收结果

- 全部 35 个目标存在，旧文件名已退出，文档效力分类保持 formal。
- 除获准新增的命名规则外，35 篇正文只调整引用路径和链接文字，没有改写概念或设计含义。
- data/ 全部文件、既有决定、根 README 和生成 glossary 均保持原字节。
- 整仓相对链接与锚点检查通过，含空格英文文件名的链接可解析。
- git diff --check 通过。本次为机械命名迁移，不重跑全量业务回归。

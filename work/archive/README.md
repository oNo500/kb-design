# 历史材料 (Work Archive)

本目录保存迁移前的实施计划、设计过程和 Obsidian 应用记录。文件正文按形成时的 Git 基线解释，旧路径和未勾选步骤不改写为当前事实，也不自动成为待办。

当前工作与后置门禁见[项目路线](../roadmap.md)，现行设计导航见[文档索引](../../docs/README.md)，旧文件到当前位置的对照见[迁移计划](../plans/2026-09-05-monorepo-layout.md)。

## 材料范围

| 目录 | 内容 |
|---|---|
| `plans/` | 原项目实施计划 |
| `specs/` | 原设计与审查规格 |
| `obsidian/` | 原 Obsidian 应用计划与执行记录 |

归档表示这些文件不再承担当前导航或待办职责，不表示其中每个步骤都已执行。是否完成、冻结或后置，须回到现行决定与[项目路线](../roadmap.md)判断。

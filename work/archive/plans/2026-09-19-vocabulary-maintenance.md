# 词表维护计划

## 目标与范围

来源清单驱动同步；不获取来源也可按概念、名称、关系、分组成员批量编辑。来源快照不修改，本地编辑及其原始上下文持久保存。再次同步使用三方比较，冲突阻止发布并支持明确解决。复用现有下载、导入、图校验、版本发布和 Skosmos 同步，不增加编辑界面或语义自动判断。

## 实施顺序

- [x] 本地编辑：新增、字段增删改、节点删除、撤销、冲突解决及并发修订检查。
- [x] 生成接入：保存未编辑基线，应用本地记录，更新分组与覆盖报告，保留归档重放。
- [x] 来源同步：由清单生成指纹和分组输入，自动处理退出来源，保留共享概念，复用来源适配器。
- [x] 操作记录：失败状态、继续执行、重复调用及应用同步独立状态。
- [x] 验收：隔离样例验证增删改和冲突，当前五份来源全量生成，更新普通和中文展示副本。

## 文件职责

本地合并、编辑存储、来源同步与命令接口位于 `packages/kb-vocab/src/kb_vocab/`；生成器负责字段、图约束与归档。配置引用本地编辑记录和来源清单，工作记录位于词表输出目录。Skosmos 保留应用端代码，Python 核心不依赖具体界面。

## 验收证据

编辑后同步不丢修改；来源字段与本地字段同时变化时报告冲突；删除记录不因重同步复活；本地新概念不随来源退出删除；失效关系明确报告；共享 URI 仍有来源支持时保留；错误或同步失败不伪报成功。测试使用隔离数据，不把示例概念写入当前词表。

## 实施结果

统一命令、三方比较和应用适配已接入。隔离数据验证了来源退出、共享 URI、本地新建及删除、逐值修改、冲突解决、并发修订和失败重试；独立复核发现的属性与反向关系边界已修复。当前五份来源完成全量生成及两个浏览副本同步，概念与原有内容保持不变。重复同步与干净环境重放验收通过。

# 项目简报 (Project Brief)

## 建设目标

以权威来源建立可维护、可核对的知识体系，统一主题名称和关系，组织教材、论文、课程、文档、代码和案例，支持标引、浏览、检索，以及知识覆盖中的缺口、重复和混淆检查。

**计算机科学是当前内容重点；认知科学和哲学是下一阶段重点；其余领域按需填充。** 各领域均需要完整、可维护的词表基础，内容建设按优先级展开。领域之间允许交叉。

## 当前范围

五份来源的离线快照及 Turtle 副本完整保留。当前自有产物已按第 3 版字段规范改为一个 ConceptScheme 和八个领域 Collection；全部 25,852 个来源概念保持原 IRI，并属于同一份自有词表。概念是否已有内容或领域分组，不影响其保留。

[组织配置](../../data/inputs/vocabulary/knowledge-system.json)与[SHACL 规则](../../data/inputs/vocabulary/shapes.ttl)共同作为生成输入。主图仅输出中英文文字，来源 Scheme 元数据、原归属和其他语言文字保留在来源副本及转换账本中。程序归一已有互反关系，不主动合并跨来源概念，不补造历史、停用、替代或译名。

`output/vocabulary/current/vocabulary.ttl` 是稳定主文件，版本在 `output/vocabulary/versions/`。当前有 14,682 个概念进入至少一个领域分组，其余 11,170 个仍完整收录。原 4,122 对候选只作按需线索，不作为生成前置任务。生成器执行图校验、SHACL、完整对账与哈希检查后才切换入口。

源中真实问题与输出校验分开。当前输出没有阻断错误，两项来源缺项继续作为警告；此前集合类型造成的 780 项工具限制已纠正。字段规范完成不等于全部领域覆盖完整，旧 YAML 消费者尚未切换，知识内容填充仍独立进行。

CS2023、IFLA、CWPA、tekom 等知识覆盖文献暂缓进一步建模；已下载材料保留。历史字段盘点和旧版本中的十四个 Scheme 是原结构记录，不是当前输出数量。

## 领域与来源

机构词表用于组织主题，课程指南和专业书籍留待检查知识覆盖。ERIC 服务于多个领域；PhilPapers 当前使用第三方缓存。

|---|---|---|

| 数学（Mathematics） | [MSC2020](sources/msc2020.yaml)：官方 TSV 分类表，文件扩展名为 `.csv`，编码为 cp1252 | MSC2020 分类说明；专业知识正文来源待选 |
| 图书馆与信息科学（Library and Information Science） | 暂无词表来源，保留空分组 | IFLA 2022 教育指南仍作知识覆盖材料 |
| 写作研究（Writing Studies） | [ERIC Thesaurus](sources/eric-thesaurus.yaml)：官方 XML，下载载体为 ZIP | [CWPA 4.0](sources/cwpa-writing-4-2026.yaml)，大学初年写作要求 |
| 技术传播（Technical Communication） | ERIC 中的技术写作主题：XML（ZIP）；专门主词表待选 | [tekom 2018](sources/tekom-teaching-2018.yaml)，教学与考试要求 |

计算机领域通过 IEEE 主题与 CS2023 知识单元的对应，检查教材、论文和实践材料的覆盖情况。CS2023 提供本科教育基线，专业深度由领域文献补充。

Cognitive Atlas 侧重认知过程和认知神经科学，其概念与任务关系用于组织具体研究主题；专业手册用于检查更广的认知科学知识覆盖。依据：[项目官网](https://www.cognitiveatlas.org/)、[官方 API](https://www.cognitiveatlas.org/api)。

LCSH、MeSH、ESCO 是补充来源候选。

## 词表表达

主题词表的目标表示采用 **RDF 数据模型、SKOS 词表语义和 Turtle（`.ttl`）文件**。Turtle 是唯一编辑格式，JSON-LD 按交换需要派生。

NISO／ISO 的词表建设原则指导概念选择、名称控制、关系组织和维护。SKOS 表达概念、首选名、替代名、层级、相关及映射关系；来源证据和审核信息使用适用的标准属性，必要的扩展单独定义。

分类层级、章节目录、课程分组和学习要求各有含义。词表上下位关系依据概念语义确定；章节位置和课程编排保留为知识覆盖线索。

概念身份按来源保留：MSC2020 用原代码生成本地 UUIDv5；PhilPapers 用原分类 ID 构成本地 URN；ERIC 使用 XML 哈希与名称生成快照内 UUIDv5。IEEE、Cognitive Atlas 首次分配 UUID，同源重建显式复用已有 Turtle。ERIC 更新快照会改变身份，须另行衔接；所有本地 URI 都不冒称官方标识。正式项目身份方案尚未统一。

## 工具与存储

| 工具 | 职责与接口 |
|---|---|
| `kb-sources` | 下载、离线校验、原文保存、结构与关系提取、来源对照 |
| [`kb-vocab`](../kb-vocab/README.md) | 使用 RDFLib 导入、读取、查询、校验和构建五源完整词表与领域组织；跨来源审查为独立可选能力 |
| 应用工具 | 读取词表，生成参考页面及其他应用结果 |

现有正式词表使用 YAML，来源转换及领域构建数据保存在 `kb-vocab/output/`。正式迁移、通用写入与应用同步属于后续工程；写入接口需要提供校验结果和可审查差异。

从仓库根目录生成到尚不存在的新目录：

```bash
uv run kb-vocab build-system \
  --config data/inputs/vocabulary/knowledge-system.json \
  --output-root output/vocabulary
```

每次构建生成新版本，校验成功后自动更新 current，既有版本不覆盖。vocabulary.ttl 是规范化后的一份自有词表；organization.ttl 保存一个 Scheme、八个 Collection 和成员关系；domains/*.ttl 是分组子集；unassigned.ttl 保留尚未分组但已纳入词表的概念。领域成员按 Collection 的 member 统计，不能数分图中所有 Concept。来源原字节、过滤及结构转换去向分别保留。

`accounting.json` 独立核对来源语句、转换记录及投影；`coverage.json` 逐概念对账，`provenance.json` 记录来源与规则位置，`manifest.json` 记录配置、来源及工具代码哈希，`validation.json` 和 `report.json` 分开列出来源诊断基线与构建新增错误。保留来源原生问题，新增错误为零且输入完整性、语句保留和往返同构检查通过后发布到新目录；这不代表完整 SKOS 合规。相同输入及规则重建保持 RDF 图同构，不宣称字节完全一致。归档的 `inputs/config.json` 引用包内来源和规则，可搬动整个版本目录后重放；仍需兼容工具环境，ERIC、IEEE、Cognitive Atlas 的明确来源键可复用旧 URI，无法判断的旧键消失停止自动替换；版本差异与环境恢复材料随构建保存。

`kb-sources` 使用成熟库直接读取 RDF、表格、XML 和 JSON，使用文档解析库提取 PDF／HTML。[文档提取结果](output/structures/2026-09-13-reviewed/index.md)保留正文、结构和原文定位，来源原件独立保存。

以下路径相对于 `packages/kb-sources/`：

| 内容 | 路径 |
|---|---|
| 来源清单 | `sources/` |
| 下载原件及记录 | `output/sources/` |
| 手动取得的原件及记录 | `output/manual/` |
| Cognitive Atlas 列表与详情快照 | `output/cognitive-atlas/` |
| 文档结构及来源转录 | `output/structures/` |
| IEEE 词条与关系转录 | `output/ieee-thesaurus/` |
| 来源对照与审查证据 | `output/reviews/` |

`output/` 保存需要备份的持久材料，`build/` 保存可清理的试验环境和临时结果，两者均由 Git 忽略。下载、转换和校验命令见 [README](README.md)。

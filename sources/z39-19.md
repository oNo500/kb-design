# ANSI/NISO Z39.19 受控词表指南

阅读笔记。全文免费：[ANSI/NISO Z39.19-2005 (R2010)](https://www.niso.org/publications/ansiniso-z3919-2005-r2010)，[PDF](http://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf)。本文只记本库引用过、且已对照原文核过的条款；全库凡引 Z39.19 条款号，以本文为准。

## 这个标准是什么

Guidelines for the Construction, Format, and Management of Monolingual Controlled Vocabularies。美国国家标准，NISO 制定，2005 年版，2010 年复审确认。把受控词表分为 list、synonym ring、taxonomy、thesaurus 四种结构，覆盖词的选择、形式、关系、显示、互操作，以及建设、测试、维护和管理系统。

## 核过的条款

| 条 | 标题 | 要点 | 本库用在 |
|---|---|---|---|
| 5.3.4 | Facet Analysis | 分面分析源自 Ranganathan 与分类研究小组，是层级之外的另一种组织方式，自下而上；适合新兴领域、跨学科、多层级边界不清、电子文档。图 4 把内容对象的属性（主题、作者、地点、格式、语言）也叫 facet | 分面的宽松用法 |
| 5.3.5 | Using Warrant to Select Terms | 选词依据三种：文献依据（领域文献的通行说法）、组织依据（使用组织偏好的词形）、用户依据（检索请求中的用法） | 收词依据；来源分级的依据 |
| 5.3.6 | Controlled Vocabulary Impact on Information Retrieval | 检索效果以查全率和查准率衡量，词表对两者都有正面影响 | 术语表 |
| 5.4 | Structure | 四种结构按复杂度递增：list、synonym ring、taxonomy、thesaurus；复杂的包含简单的 | 受控词表的形态 |
| 6.2.1 | Homographs | 同形异义词用括号限定词区分，限定词是词的一部分；能用自然语言的复合词就不用限定词 | id 规则的限定词 |
| 7.7 | Node Labels | 不为在层级里凑一个分组层而造复合词，用节点标签 | 节点标签规则 |
| 8.3.5 | Node Labels in Hierarchies | 节点标签标明一组兄弟的划分原则，如 cars / by motive power / by purpose；不是词，不能标引；排版上与词区分 | 节点标签规则 |
| 8.4.3 | Node Labels for Related Terms | 相关词来自不同分面时，可用节点标签按分面分组 | 分面名作节点标签 |
| 11.1.1 | Avoid Duplicating Existing Vocabularies | 新建词表前先查已有词表是否覆盖同一或重叠领域；相关领域的词表是有用的起点 | 借入知识体系 |
| 11.1.3 | Construction Methods | 委员会法（自上而下 / 自下而上，新建优先自上而下）；经验法（演绎：先收集后控制；归纳：从头控制）；机器辅助：自动识别候选词、登记标引频率、记录用户查询 | 建设方法；回流的三个输入 |
| 11.1.4 | Term Records | 每个词入表时建记录：词、来源（对新词尤其重要，可引出版物或咨询的人）、范围注释、UF、不显示的变体、BT / NT / RT、本地关系、类目号、历史注释 | 概念记录字段；断言的依据 |
| 11.1.5 | Term Verification | 候选词入表前按第 6、7 章核词形与范围，并对照技术词典、已有词表、分类法 | 来源优先政策 |
| 11.1.6 | Candidate Terms | 候选词（provisional term）是未走完审批的词，记录里加特殊标记；批准后删标记；联机系统一般不向用户显示 | 状态 candidate |
| 11.1.7 | Levels of Specificity | 高度具体的词只限于核心领域；边缘领域的细词让词表难管理，人工建关系成本高 | 借入深度 |
| 11.1.8 | Unassigned Terms | 为补全层级而收进、尚未用于标引的词是允许的 | 状态 unassigned |
| 11.3 | Maintenance | 每次变更记日期和责任人 | 留痕 |
| 11.3.1 | Updating the Vocabulary | 词表是语言的反映，是动态工具；要有定期复审、新增、替换废弃词的政策与流程。11.3.1.1 加词：标引者或检索者提名候选词，编辑（最好有编委会）审核，四问：已被覆盖？要注释？词形？关系？11.3.1.2 改词：记历史注释，旧形式到新形式加 USE。11.3.1.3 删词：过度使用和极少使用的词都是修改或删除的候选；过度使用的可拆成更具体的词 | 审核四问；过度使用信号 |
| 11.3.2 | Vocabulary Updates and Database Records | 删改要考虑对已标引记录的影响。11.3.2.1 三种处理：保留仅供检索并标记、一对一替换、复杂替换需人工；删词不替换会降低访问；只有误建且已清出记录的才删。11.3.2.2 每个词有历史注释记入表日期、变更、旧形式及有效期；完全删除的另存一份 | 不删政策；历史注释 |
| 11.4.4 | Term Deletion | 删词时系统应要求确认，自动删除互反关系，产生孤儿词时提醒 | 校验规则 |
